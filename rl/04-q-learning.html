第 04 天｜Q-learning：从一条经验开始，学会比较未来

系列首页 · 上一篇 · 下一篇

原论文与版本：Watkins & Dayan，Q-learning，1992。原文。1989 年博士论文提出算法，此篇重点是收敛证明。

一、先用一分钟讲明白

研究问题：未知环境中的最优行动选择

旧方法卡点：动态规划需要转移模型，表格中每个动作的长期后果尚不可知

作者主张：用采样 Bellman 最优目标逐项更新 Q

论文证据：§3 的定理在有限状态动作、充分访问与合适步长等条件下给出几乎必然收敛

一句话：在单智能体、在线采样、无模型、off-policy 的有限 MDP中，作者通过“用采样 Bellman 最优目标逐项更新 Q”应对“未知环境中的最优行动选择”这一问题；证据边界或代价是：渐近结论没有承诺有限预算速度，也不能直接覆盖神经网络。

五个前置概念

  1. MDP：当前状态包含预测下一步所需的信息。
  2. Q 值：一个状态动作对的未来累计回报。
  3. Bellman 最优性：最优价值与下一状态的最优选择相一致。
  4. TD 误差：当前目标与当前价值估计的差。
  5. off-policy：采集经验的行为与更新所针对的策略可以不同。

二、研究背景与问题定义

Q 不是当前奖励，而是执行一个动作后继续行动的累计收益。难点在于现在不知道未来，又希望从有限经验开始学习。本文以 1992 年收敛证明为中心；算法在 Watkins 1989 年博士论文中已有提出。探索行为与被评价的最优策略可以不同，这是理解 off-policy 的第一处入口。证明要求环境规律固定、奖励有界；这些前提不能被“网络足够大”替代。

要素 本文设定
研究场景 单智能体、在线采样、无模型、off-policy 的有限 MDP
状态／观测 可枚举的状态 s
动作 有限动作 a
奖励或学习信号 有界标量 r，通常折扣 γ<1
终止／边界 真实终止令未来值为零；继续任务另按折扣处理

三、方法：到底改了什么

沿用 Bellman 最优性关系，但不显式计算所有后继状态的概率加权平均，而以一次真实转移代替该期望。每次只修正当前访问的表项。没有独立 Actor、Critic 网络或环境模型；Q 表既提供学习量，也提供贪心行动依据。学习率控制新信息与旧信息的混合，探索规则控制能否获得必要的信息。

关键公式与符号

yt=rt+γmax⁡bQt(st+1,b),δt=yt−Qt(st,at),Qt+1(st,at)=Qt(st,at)+αtδt.y_t=r_t+\gamma\max_b Q_t(s_{t+1},b),\quad \delta_t=y_t-Q_t(s_t,a_t),\quad Q_{t+1}(s_t,a_t)=Q_t(s_t,a_t)+\alpha_t\delta_t.yt​=rt​+γbmax​Qt​(st+1​,b),δt​=yt​−Qt​(st​,at​),Qt+1​(st​,at​)=Qt​(st​,at​)+αt​δt​.

γ 决定未来奖励的折扣，α 是更新幅度。真正终止时 y=r。对每一状态动作的访问子序列要求 ∑αt=∞\sum\alpha_t=\infty∑αt​=∞ 且 ∑αt2<∞\sum\alpha_t^2<\infty∑αt2​<∞：前者避免太早停止学习，后者抑制累积噪声。它们与无限访问条件一起使用。

输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。

输入：有限状态动作空间，折扣 γ，学习率日程
初始化所有 Q(s,a)，访问计数 N(s,a)=0
重复采集回合：
  s ← reset()
  while 未真正终止：
    a ← 有探索的行为策略(Q,s)
    r,s_next,terminated ← step(a)
    N(s,a) += 1
    if terminated: y ← r
    else: y ← r + γ max_b Q(s_next,b)
    Q(s,a) ← Q(s,a)+α[N(s,a)]*(y-Q(s,a))
    s ← s_next
输出：π(s) ∈ argmax_a Q(s,a)

固定 ε 的 ε-greedy 是教学采样选择，不自动证明所有状态都可达。代码中用每个表项的访问计数确定步长，比只按全局时间递减更贴近定理条件。有限训练不得因曲线暂时平稳就宣称满足无限时间结论。

四、实验如何验证方法

实验要素 原文设定与证据范围
环境与任务 理论有限 MDP；不是 Atari 实验
数据来源与规模 随机转移流，关键是每一状态动作无限访问
对比基线 Bellman 最优解是理论参照
训练预算与资源 渐近分析，无 GPU 或固定训练预算
指标及其含义 几乎必然收敛，不是平均成功率
随机性与不确定性 概率 1 的理论结论；随机种子表不适用
实际验证的假设 不用已知模型的异步更新能否得到最优 Q

实验解读（本文分析）：把定理作为证据时，公平性问题变为前提是否真的满足：可达性、采样覆盖、固定转移和步长不可忽略。不能把证明用的 action-replay process 写成已验证的经验回放训练技巧。

五、结果：证据到底有多强

证据定位 比较什么／观察到什么 支持什么 不能证明什么
§2 定义问题和采样更新 明确学习对象是 Q* 不提供有限样本误差
§3 主定理 随机更新与最优 Q 比较 满足条件时几乎必然收敛 不保证神经网络稳定
附录 action-replay process 把更新历史对应到辅助决策过程 支撑收敛证明 不是现代 replay 的性能消融
§4 扩展 讨论更一般的终止或更新情形 结论可在附加条件下延伸 不意味着 γ=1 任意任务都收敛

Q-learning 的核心证据是一条有条件的收敛定理：在充分访问和合适步长等前提下，表格估计最终到达最优 Q 值。有限预算内需要多久、探索是否足够，仍需另行分析。

六、贡献、代价与局限

作者证明的贡献是为无模型最优控制提供收敛基础。本文分析是它把难题从“知道动力学”转移为“获得充分而持续的经验”。大状态空间使表格不可行；不充分探索无法确认未访问动作。与函数逼近、bootstrapping、off-policy 同时结合时，不能照搬本定理。

七、帮助建立理解

教学例子

以下是教学推演，不是原论文实验。

设当前 Q=2，r=1，下一状态最大 Q=4，γ=0.9，α=0.1。目标为 4.6，误差为 2.6，更新得到 2.26。若这步真正终止，目标变成 1，更新为 1.9。只改一个终止标志，方向就完全不同，说明终止处理不是无关紧要的工程细节。

三个值得继续追问的问题

  1. 固定探索概率能否保证所有表项无限访问？还缺哪些环境条件？
  2. α 长期保持常数时，确定环境和随机环境会有什么不同？
  3. 把表格换成共享参数网络，证明中哪一步失去了保障？

自测两题

第一题考查核心机制，第二题考查边界与辨析。建议先自行作答，再对照参考答案。以下数值小例子均为教学构造。

问题 1：为什么执行的是探索策略，Q-learning 却可以学习最优策略的价值？

参考答案：采样决定“观察什么”，更新目标决定“评价什么”。它使用：

Q(s,a)←Q(s,a)+α[r+γmax⁡bQ(s′,b)−Q(s,a)]Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_bQ(s',b)-Q(s,a)]Q(s,a)←Q(s,a)+α[r+γbmax​Q(s′,b)−Q(s,a)]

下一步取最大值，针对的是最优控制目标，而不是实际探索动作。因此行为策略与学习目标可以不同，这就是其 off-policy 特征。

问题 2：每个动作都尝试过一次，为什么不能保证学到最优 Q？

参考答案：一次观察无法可靠估计随机结果，也未必访问了所有相关状态。经典表格收敛结论要求适当的环境条件、持续充分访问，以及满足条件的学习率。它是渐近结果，不保证有限次数训练足够，也不能直接推广到任意神经网络。
