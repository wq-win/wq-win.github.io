## 三、方法：到底改了什么

本文以 1990 年 NIPS 论文为依据；它与同年 ICML 的 Dyna 论文是两篇相关工作。Dyna-AHC 将评价、行为和模型组合；教学伪代码聚焦较简单的 Dyna-Q。真实转移同时更新 Q 和模型，随后在已见状态动作上产生模拟转移。规划是在参数中积累结果，执行动作时不必进行一整棵树搜索。

### 关键公式与符号

真实更新与规划更新共享 $Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_bQ(s',b)-Q(s,a)]$。区别在于 $(r,s')$ 来自真实环境还是 $\hat M(s,a)$。规划次数 n 增大不增加真实信息量，只增加对已有模型的利用。

### 输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。

```text
输入：Q、模型 M、每步规划次数 n
每次真实交互：
  a ← ε-greedy(Q,s)
  r,s_next,done ← 环境执行 a
  用真实转移做一次 Q 更新
  用 (s,a,r,s_next,done) 更新 M
  重复 n 次：
    抽取已见过的 (s_sim,a_sim)
    r_sim,next_sim,done_sim ← M(s_sim,a_sim)
    用模拟转移做同一种 Q 更新
  s ← s_next 或回合重置
输出：Q 与可用的环境模型
```

**实现要点**：此处使用最基本模型回放，不把探索奖励或优先规划当作所有 Dyna 的必选模块。

### 三种“优化”要分开

| 层次 | 这里具体是什么 |
|---|---|
| 数学目标／训练损失 | 任务回报最大化；真实和模型经验共同进行Bellman更新 |
| 机制改变 | 学习环境模型，并把模型生成的一步经验送入同一更新器 |
| 评价改善的指标 | 到达目标、路线适应和学习进程 |

## 六、贡献、代价与局限

**作者贡献**是整合架构而非某一深度损失。**本文分析**：真实经验是纠错源，模拟经验不能发现模型不知道的改变。比较样本效率应报告环境步数，比较实际效率还需模型拟合与规划时间。它与 MBPO、Dreamer 的共同问题是何时值得相信模型。

## 七、帮助建立理解

### 教学例子

以下是教学推演，不是原论文实验。

已知 A→B→目标，但只刚刚在 B 获得成功奖励。纯一步 Q 更新需再次访问 A 才能传播；Dyna 可立即从模型回放 A→B。若 B→目标实际已经封路，重复回放反而会使过时路线显得更好。

### 五个前置概念

1. **环境模型**：预测动作的下一状态与奖励。
2. **规划**：利用模型进行决策计算。
3. **真实样本**：来自环境而非模型的经验。
4. **模拟样本**：从学习模型生成的经验。
5. **模型偏差**：模型与真实环境的系统差异。

### 三个值得继续追问的问题

1. 固定总计算预算，规划 n 次是否仍优于更多真实交互？
2. 环境出现新捷径时，旧模型如何发现？
3. 何时应该停止规划并去收集新证据？
