# 强化学习 60 篇论文：从预测、控制到推理与 Agent

强化学习算法看似分支繁多，核心问题却彼此相连：价值如何估计，策略如何更新，经验从哪里来，奖励又如何分配到动作。

本系列以 60 篇代表论文为线索，串联早期控制、深度价值学习、策略梯度、探索与模仿、多智能体、离线学习、世界模型和语言模型强化学习。每篇均可独立阅读，也可以每天一篇，逐步建立知识框架。

**阅读入口**：先用[Day 0导读](00-reading-guide.md)辨认数据、目标和学习信号，再用[强化学习发展时间线总览](00-强化学习发展时间线总览.md)呈现各阶段的问题与方法；下方目录连接逐篇精读，收尾篇提供横向比较和实验设计。

## 读每篇时找这几件事

1. **承接哪个问题**：此前方法的瓶颈是什么，本篇真正改变哪个环节，后作又接走什么。
2. **设定与推导**：先说明信息、目标、符号与假设，再展开关键中间步骤和可手算例子。
3. **看得见的证据**：具体图表旁给原页入口、读法及实验条件；[第2天TD(λ)](02-td-lambda.md)还直接展示任务示意、正式勘误图与两张实验图。
4. **带着答案追问**：前置概念先读，进阶问题可展开参考答案；回答区分论文结论、教学推演和仍需实验的判断。

不同论文不强行套同一节标题。伪代码强调采样、梯度和更新顺序，不能仅凭几行教学流程就宣称复现训练结果。

## 全系列架构图

```mermaid
flowchart TD
  RL[强化学习：序列决策] --> V[价值学习]
  RL --> P[策略梯度]
  RL --> M[模型学习与规划]
  RL --> X[其他研究维度]
  V --> TD[TD → Q-learning / SARSA → Double Q]
  TD --> DQN[DQN → Double DQN / PER / Dueling → C51 / Rainbow]
  P --> PG[REINFORCE → 策略梯度定理 → 自然梯度 → TRPO / PPO]
  P --> AC[Actor–Critic：策略与价值协作]
  AC --> CONT[DPG → DDPG → TD3]
  AC --> SAC[SAC：最大熵随机策略]
  AC --> ASYNC[A3C → IMPALA]
  M --> DYNA[Dyna → PETS / MBPO]
  M --> WM[Dreamer → DreamerV3]
  M --> SEARCH[AlphaGo → MuZero]
  X --> OFF[离线：LSPI → BCQ / BEAR / CQL / IQL / DT]
  X --> EXP[探索与技能：ICM / HER / RND / DIAYN / Options]
  X --> MULTI[多智能体：MADDPG / QMIX]
  X --> IM[模仿与偏好：GPS / GAIL / InstructGPT / DPO / IPO / KTO]
  PG --> LLM[语言模型 RL：GRPO → R1；GRPO → DAPO / Dr. GRPO]
  LLM --> NEW[2026：测试时适应与 Agent 信用分配]
```

这些维度不是互斥分类。PPO 常与 Critic、GAE 配合；SAC 是无模型 Actor–Critic；Dreamer 同时包含世界模型与 Actor–Critic。DPO 在偏好学习设定下直接优化策略，但不能简单等同于通用在线策略梯度。

## 带着一个问题进入，而不是把目录当升级榜

- **为什么梯度长这样？** [REINFORCE](05-reinforce.md) → [策略梯度定理](08-policy-gradient-theorem.md) → [自然梯度](09-natural-policy-gradient.md) → [TRPO](14-trpo.md) → [PPO](27-ppo.md)。中途单独插入[GAE](15-gae.md)，核对估计器和优化器的分工。
- **固定数据能信多少？** [LSPI](10-lspi.md)给出批量策略迭代入口，再并列读[BCQ](37-bcq.md)、[BEAR](38-bear.md)、[CQL](42-cql.md)、[IQL](46-iql.md)。分别问限制动作、支持、价值还是查询，不把年份当性能顺序。
- **世界模型省了哪种成本？** [Dyna](03-dyna.md) → [PETS](35-pets.md)，再对照[MBPO](39-mbpo.md)、[Dreamer](40-dreamer.md)和[MuZero](41-muzero.md)：模型经验、想象训练和行动时搜索的账本不同。
- **语言反馈怎样进优化？** 从[InstructGPT](47-instructgpt.md)分叉到[DPO](49-dpo.md)/[IPO](50-ipo.md)/[KTO](51-kto.md)的离线反馈目标，或[GRPO](52-grpo.md)/[R1](53-r1.md)的在线采样与奖励。数据接口和优化器不是同一分类轴。
- **一条成功轨迹应该奖给谁？** 先做[Dr. GRPO](55-dr-grpo.md)的分母手算，再比较[FACTOR](58-factor.md)与[DRACO](60-draco.md)的守恒对象，最后看[TTPO](59-ttpo.md)多出的测试时权限。

每篇“一分钟理解”后都有独有路线提示；正文关系明确标为本篇承接、后作承接、模块组合、并行路线或教学对应。上一篇/下一篇只是阅读导航，不作为机制祖先的证据。

## 收尾与阅读路线

[系列收尾：三个自构实验、三处具体疑点、统一比较与阅读记录](61-系列收尾.md)

按日期通读适合建立历史脉络；需要快速搭建最小基础时，可先走 Q-learning → REINFORCE → DQN → DPG／DDPG → TRPO／GAE／PPO → TD3／SAC，再进入自己的专题。

**进一步阅读的方向**包括约束与安全 RL、风险敏感 RL、部分可观测控制、元强化学习、后悔界、探索复杂度、逆强化学习理论和全部机器人实践。这些专题可以在掌握本系列的基本方法后继续展开。

学习检查：每篇读完，独立画信息流、写一个核心更新、复述一个有条件的证据，并构造一种失败情形。具体评估记录表见收尾篇。

## 选文与证据说明

目录按所选论文首次公开或相应历史版本的年份排列，同年兼顾先修关系。DQN 采用 2015 年 Nature 版本，文内另述 2013 年预印本；BCQ 对应 2018 年预印本与 2019 年会议论文。2026年专题选文范围截至9月8日；本轮图表与问答修订日期为10月14日。首发年份与实际阅读修订版分开记录。

文章分别标明作者主张、论文证据与教学分析。论文成绩引自作者报告，教学手算单独标注；本系列未独立运行原论文训练。理论文章以证明及其前提为主要证据。

[早期 Actor–Critic](01-actor-critic.md)和[SARSA](06-sarsa.md)的原始资料获取受限，具体范围在文首说明。本轮仍只能可靠读取摘要或书目信息，其原实验图表与数值尚未全部核实；其余58篇按明确章节核源，不冒称全部全文审计。各篇的引用版本、原图入口与限制可从[逐篇查核记录](../edition-review.html)查看。
