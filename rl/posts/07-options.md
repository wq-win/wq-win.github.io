## 三、方法：到底改了什么

一个 option 是三元组 (I,π,β)：在哪里可开始、开始后怎么走、何时停止。它是闭环行为，不是固定动作脚本：途中观测可以改变下一步。call-and-return 的上层等技能结束后再选择。原论文还讨论模型、规划、intra-option 学习与中断，以下只实现基本 SMDP 更新。

### 关键公式与符号

$$Q(s,o)\leftarrow Q(s,o)+\alpha[\sum_{j=0}^{k-1}\gamma^j r_{t+j}+\gamma^k\max_{o'}Q(s_{t+k},o')-Q(s,o)].$$

k 是技能实际持续时间，所以未来价值要乘 γ 的 k 次方。若漏掉 k，长技能会被错误估值；最终可选技能还须满足启动集合。

### 输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。

```text
输入：固定 options (I_o,π_o,β_o)
上层处于状态 s：
  从可启动 options 中探索选择 o
  R ← 0；k ← 0；s_start ← s
  repeat：
    a ← π_o(s)；r,s_next,done ← step(a)
    R ← R+γ^k*r；k ← k+1；s ← s_next
  until done 或 β_o(s) 采样为终止
  y ← R if done else R+γ^k*max_可启动o' Q(s,o')
  Q(s_start,o) ← Q(s_start,o)+α*(y-Q(s_start,o))
输出：上层 option 策略
```

**实现要点**：该伪代码假设技能给定，技能发现属于另一个学习问题；终止概率与环境 done 不是同一个量。

## 六、贡献、代价与局限

**作者主张**是统一多个时间尺度的表示、规划与学习。**本文分析**：不好的技能可能把最优动作挡在技能内部，持续太久还会降低纠错速度。option 数多不等于真正丰富，技能覆盖与可终止性都重要。

## 七、帮助建立理解

### 教学例子

以下是教学推演，不是原论文实验。

到门口 option 花三步，每步 −1，γ=0.9，门口下一技能价值 10。目标是 −1−0.9−0.81+0.9³×10=4.58。若错误只乘一次 γ，会得到 6.29，把较长技能算得过好。

### 五个前置概念

1. **时间抽象**：用多步行为作为决策单位。
2. **启动集合**：允许开始某技能的状态。
3. **内部策略**：技能执行期间的反馈控制。
4. **终止函数**：决定何时归还上层控制。
5. **SMDP**：决策间隔允许变化的决策过程。

### 三个值得继续追问的问题

1. 哪类 option 会损失原始最优策略的表达能力？
2. 如何公平比较一次上层决策与十次原始动作？
3. 为什么固定技能发现与技能选择应分开评测？
