# 第 58 天｜FACTOR：先分配动作信用，再决定哪些token承担它

**原论文与版本**：Ma 等，*How Much, Then Where: Credit-Conserving Action-to-Token Allocation for Multi-Turn Agent Reinforcement Learning*，2026-08-07。[正文](https://arxiv.org/html/2608.07118v1)。

## 一、先用一分钟讲明白

**研究问题**：多轮Agent中轨迹、动作和token三层信用混杂

**旧方法卡点**：整轨迹优势广播太粗，教师token权重又会无意改变动作总量

**作者主张**：用边界校准TD分动作信用，再用均值为1的非负token权重分配

**论文证据**：三个Agent环境及消融支持两阶段接口，动作TD信用贡献较大

**一句话**：在多轮Agent RL与可恢复环境状态中，作者通过“用边界校准TD分动作信用，再用均值为1的非负token权重分配”应对“多轮Agent中轨迹、动作和token三层信用混杂”这一问题；证据边界或代价是：代数守恒不是因果正确，也不是梯度向量守恒。

## 二、研究背景与问题定义

本篇将“多轮Agent中轨迹、动作和token三层信用混杂”放在多轮Agent RL与可恢复环境状态的边界内研究。整轨迹优势广播太粗，教师token权重又会无意改变动作总量。先固定下表中的任务、反馈与信息权限，再判断后面哪一项改动真正回答了这个问题；算法机制有效与适用于任意环境是不同结论。

| 要素 | 本文设定 |
|---|---|
| 研究场景 | 多轮Agent RL与可恢复环境状态 |
| 状态／观测 | 每次动作前的完整历史x_t |
| 动作 | 由多个token组成的可执行动作 |
| 奖励或学习信号 | 真实环境奖励／终局回报 |
| 终止／边界 | 有限回合，γ=1；首尾势函数固定 |

## 三、方法：到底改了什么

TAC借助中间状态续跑校准价值，动作信用由TD残差给出。HTA让冻结教师看到动作后的反馈，计算与学生的token似然差。APM把非负权重归一到每动作均值1。损失先在动作内平均token，再平均动作，保证指定位置的标量贡献不被长度改变。

### 关键公式与符号

$$A_t^*=r_t+\widetilde V(x_{t+1})-\widetilde V(x_t),\quad\widetilde V(x_0)=b,\ \widetilde V(x_T)=0,\quad\sum_tA_t^*=G-b.$$
$$C_{t,j}=A_t^*\omega_{t,j},\quad\frac1{L_t}\sum_j\omega_{t,j}=1.$$
守恒对象是信用系数／旧策略处裁剪前标量surrogate，非任意参数位置的梯度总和。

### 输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。`stop_gradient` 表示停止向目标量传播梯度。

```text
用冻结行为策略采多轮轨迹
选择少量中间checkpoint，恢复环境并采续跑
用续跑回报校准价值头
设置首势函数=b、末势函数=0
计算每动作TD信用A_star
教师看到动作后反馈，重评分动作token
将sign-aware分数变成非负权重并按动作归一均值1
C_token←stop_gradient(A_star*weight)
对token构造裁剪项，先动作内平均再跨动作平均
保留原文辅助蒸馏损失并更新策略
```

**实现要点**：代数守恒不是因果正确，也不是梯度向量守恒。

### 三种“优化”要分开

| 层次 | 这里具体是什么 |
|---|---|
| 数学目标／训练损失 | 动作内均值保持的裁剪目标，加非动作分支和原辅助损失 |
| 机制改变 | 用边界校准TD分动作信用，再用均值为1的非负token权重分配 |
| 评价改善的指标 | 成功率、信用守恒与跨骨干表现 |

## 六、贡献、代价与局限

**作者明确**区分真实值TD解释与边界调整后记账恒等式。**本文分析**：恢复环境状态和教师看后验反馈属于额外训练能力；token似然差是分配启发，不是独立token因果贡献。非负权重保留每个动作信用的符号。

## 七、帮助建立理解

### 教学例子

以下是教学推演，不是原论文实验。

G=1、b=0.2，中间势函数0.9，两动作奖励0、1。信用为0.7与0.1，总和0.8。把中间值错估为10，信用变为9.8与−9，总和仍0.8；总和正确丝毫不能证明每步判断合理。

### 五个前置概念

1. **TAC**：用TD分解动作级信用。
2. **Hindsight教师**：训练时看到动作后反馈的重评分者。
3. **均值保持**：归一化后不改变动作平均系数。
4. **望远镜求和**：中间相邻项相消只剩首尾。
5. **Action-mean**：先在每个动作内平均再跨动作聚合。

### 三个值得继续追问的问题

1. 若中间价值严重不准，守恒是否仍帮助训练？
2. 梯度方向不守恒为何不与标量守恒矛盾？
3. 无法恢复工具环境状态时如何校准价值？
