# 第 11 天｜Double Q-learning：为什么取最大值会制造乐观偏差

## 一、先用一分钟讲明白

**研究问题**：噪声价值估计中的最大化偏差

**旧方法卡点**：同一个带噪估计同时选动作又评价动作，容易挑中正误差

**作者主张**：用两套价值估计分离动作选择与动作评价

**论文证据**：理论双估计分析、收敛结果和随机环境例子支持减轻高估

**一句话**：在表格、无模型、off-policy 控制中，作者通过“用两套价值估计分离动作选择与动作评价”应对“噪声价值估计中的最大化偏差”这一问题；证据边界或代价是：双估计也可能低估，两个估计高度相关时收益有限。

## 三、方法：到底改了什么

分两张表并不等于取它们的最小值。更新 A 时，先用 A 的 argmax 选下一动作，再让 B 评价它；更新 B 时交换角色。选择偏爱 A 的正噪声，不一定也偏爱 B 的正噪声。TD3 的 min 双 Critic 是另一种设计，不应混在同一伪代码里。

### 关键公式与符号

$$a^*=\arg\max_a Q_A(s',a),\quad y=r+\gamma Q_B(s',a^*).$$
$q$ 的带噪估计满足 $\mathbb E\max_a\hat q_a\ge\max_a\mathbb E\hat q_a$。这不等于 Double Q 对每次样本都准确，也不表示误差从此为零。

### 输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。

```text
初始化 Q_A,Q_B
用 Q_A+Q_B 的探索策略采样转移
每条转移随机选择一个表更新：
  若更新 A：
    a_star ← argmax Q_A(s_next,a)
    y ← r if done else r+γ*Q_B(s_next,a_star)
    Q_A(s,a) += α*(y-Q_A(s,a))
  否则交换 A 与 B 执行同一过程
输出：两表组合产生的策略
```

**实现要点**：双估计也可能低估，两个估计高度相关时收益有限。

## 六、贡献、代价与局限

**作者指出**双估计有时会低估。**本文分析**：增加估计器意味着样本分配更复杂；一个估计对另一个不够独立时，选择偏差仍会残留。性能要同时看真实回报，不能只优化“Q 看起来不高”。

## 七、帮助建立理解

### 教学例子

以下是教学推演，不是原论文实验。

两个动作真值都为0。一次 A 估计为(1,−1)，B 为(−0.2,0.2)。单表最大值为1；A 选择第一个动作，B 给目标−0.2。这次纠正了正偏差却低估了真值，说明降低高估不等于逐次准确。

### 五个前置概念

1. **最大化偏差**：选择最大噪声估计产生乐观倾向。
2. **双估计**：将选择和评价交给不同估计器。
3. **估计相关性**：两套误差是否一起变化。
4. **低估**：预测低于真实期望。
5. **随机逼近**：用采样更新渐进逼近期望方程。

### 三个值得继续追问的问题

1. 两张表完全共享噪声时还能减轻偏差吗？
2. 真值差很大与几乎相等时，偏差风险有何不同？
3. 取 min 和交叉评价分别解决什么问题？
