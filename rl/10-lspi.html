一、先用一分钟讲明白

研究问题：有限经验下怎样高效评价并改善策略

旧方法卡点：普通 TD 小步更新可能反复消耗样本，状态价值评价难直接支持 off-policy 控制

论文证据：论文理论与控制实验展示固定样本的重复利用

一句话：在基于批量转移、无模型、近似策略迭代中，作者通过“把最小二乘 TD 扩展到动作价值，交替求解线性系统和贪心改进”应对“有限经验下怎样高效评价并改善策略”这一问题；证据边界或代价是：线性特征、数据覆盖与矩阵条件决定可用性。

五个前置概念

  1. 策略迭代：交替评价与改善策略。
  2. 线性价值逼近：Q 是固定特征的线性组合。
  3. 投影 Bellman 方程：把目标映射回可表达函数空间。
  4. 条件数：衡量矩阵求解对误差的敏感性。
  5. 数据覆盖：样本是否包含决策所需信息。

二、研究背景与问题定义

本篇将“有限经验下怎样高效评价并改善策略”放在基于批量转移、无模型、近似策略迭代的边界内研究。普通 TD 小步更新可能反复消耗样本，状态价值评价难直接支持 off-policy 控制。先固定下表中的任务、反馈与信息权限，再判断后面哪一项改动真正回答了这个问题；算法机制有效与适用于任意环境是不同结论。

三、方法：到底改了什么

LSPI 的 Critic 是 Q_w(s,a)=φ(s,a)ᵀw。给定当前策略，用 LSTDQ 的矩阵方程评价它；再把策略改成此 Q 的贪心策略。关键是原始转移仍可重用，而每轮后继动作特征会随策略改变。它不是监督学习中固定标签的一次线性回归。

关键公式与符号

A=∑iϕi(ϕi−γϕ(si′,π(si′)))⊤,b=∑iϕiri,Aw=b.A=\sum_i\phi_i(\phi_i-\gamma\phi(s'_i,\pi(s'_i)))^\top,\quad b=\sum_i\phi_i r_i,\quad Aw=b.A=i∑​ϕi​(ϕi​−γϕ(si′​,π(si′​)))⊤,b=i∑​ϕi​ri​,Aw=b. A 一般不是普通回归的对称协方差矩阵。求解的是投影 Bellman 固定点，不能随意等同于最小化逐样本 Bellman 残差。

输入 → 处理 → 输出：教学伪代码

以下伪代码展示核心更新流程；简化条件见代码注释与后文。

输入：固定转移集 D 与特征 φ；初始策略 π
repeat：
  A ← 0；b ← 0
  for (s,a,r,s_next,done) in D：
    x ← φ(s,a)
    x_next ← 0 if done else φ(s_next,π(s_next))
    A += x*(x-γ*x_next)ᵀ；b += x*r
  解 Aw=b（必要时明确数值正则）
  π_new(s) ← argmax_a φ(s,a)ᵀw
  判断策略或参数是否收敛
  π ← π_new
输出：Q_w 与 π

实现要点：线性特征、数据覆盖与矩阵条件决定可用性。

六、贡献、代价与局限

作者贡献是把样本高效的最小二乘评价变为控制方法。本文分析：稀疏覆盖会使矩阵病态，也会让贪心策略追逐不可信动作；后来离线 RL 对分布外动作的限制正补这一类风险。

自测两题

第一题考查核心机制，第二题考查边界与辨析。建议先自行作答，再对照参考答案。以下数值小例子均为教学构造。

问题 1：固定的一批经验为什么可以反复用于不同策略的评价？

参考答案：转移数据记录的是环境关系，而当前待评价策略决定下一状态采用哪个动作。LSPI 每轮根据当前策略重新构造价值评价问题，再据此改进策略。数据不变，但评价对象以及对应的线性方程会变化。

问题 2：为什么精确解出线性方程，也可能得到很差的策略？

参考答案：方程只在给定特征和数据覆盖下成立。特征可能无法表达真实价值，数据可能遗漏关键状态动作，矩阵也可能病态。数值求解准确，只说明解决了这个近似问题，不说明近似问题足以代表真实任务。
