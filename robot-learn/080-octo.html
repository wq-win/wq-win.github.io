080｜Octo：可适配的通用机器人策略

系列首页 · 上一篇 · 下一篇

原论文：Octo: An Open-Source Generalist Robot Policy，Octo Model Team，2024。论文。

一、一分钟理解：通用策略首先要允许接口变化

机器人实验室换一只机械臂，常常连输入和输出维度都会改变：原来只有外部相机，现在多了腕部相机；原来预测末端增量，现在要预测两个手臂的关节位置。如果模型只能接受固定格式，“通用”便只剩下在同一接口中识别更多物体。

Octo 把任务、观测和动作接口拆成模块，用大量机器人示范预训练共享 Transformer，再通过新输入编码器和输出头适配下游平台。它的动作生成器使用扩散模型，既能表示多种可行行动，又保留连续动作的精度。

最重要的结果不是“任何机器人开箱即用”，而是少量目标示范可以把预训练模型适配到新传感器、动作空间和双臂平台。开箱即用实验主要使用预训练中出现过的机器人与任务类型，新平台实验则需要微调。

一句话：在机器人操作接口多样、目标示范有限的场景，通过模块化多模态策略预训练，改善下游学习效果，代价是庞大的上游示范与算力，以及依然存在的技能泛化边界。

五个前置概念

五个前置概念：行为克隆拟合示范动作；条件扩散从噪声恢复条件下的动作样本；注意力掩码规定信息允许流向；动作分块预测连续未来动作；接口适配把新传感器和执行器的物理语义接到已有模型。

二、背景与设定

这是离线模仿学习。训练样本包含图像历史、语言或目标图像以及专家动作；没有价值函数、环境模型或在线奖励优化。因此，动作生成中的“扩散步”不是机器人与环境交互的一步。

预训练主要采用末端增量控制数据，下游可以重新定义动作头。任务目标由语言或图像提供；训练标签是示范动作，部署成功则由具体任务判据衡量。动作预测误差低，不自动意味着长时序任务成功。

问题有三个层次：跨数据集共享控制知识、缺失模态仍能训练、换接口时保留已有参数。把所有图像简单拼接只能处理固定相机数量；把所有动作强行投到相同维度，则可能混淆关节位置和末端位移的物理意义。

阅读范围：依据 2024 年 v1 正文与附录，核查架构、混合数据、训练预算、下游配置及消融。本文没有独立复现；未确认每个结果的独立训练随机种子数量。

三、方法：共享内部计算，保留接口语义

1. 任务和观测变成 token

语言由冻结的 T5 编码，图像经浅层卷积和 patch 化。任务 token、各时间步观测 token 以及读出 token 被送入 Transformer。

关键不是所有 token 彼此都看见，而是分块注意力：观测只读取当前与过去信息和任务；缺失模态被屏蔽；读出 token 可以读取观测，但不反过来改变观测 token 的表示。这样新增动作头时，原有主干的输入语义不必被重定义。

用教学记号表示：

zt=Tθ(Ttask,To,≤t,Tread,t;M),At∼pψ(A∣zt).z_t=T_\theta\big(\mathcal T_{\mathrm{task}},\mathcal T_{o,\le t},\mathcal T_{\mathrm{read},t};M\big), \qquad A_t\sim p_\psi(A\mid z_t).zt​=Tθ​(Ttask​,To,≤t​,Tread,t​;M),At​∼pψ​(A∣zt​).

MMM 是注意力掩码，At=(at,…,at+H−1)A_t=(a_t,\ldots,a_{t+H-1})At​=(at​,…,at+H−1​) 是动作块。新增传感器仍需要编码与训练；模块化不意味着新来的力传感器读数会自动有意义。

2. 主干只运行一次，扩散头运行多次

给定 ztz_tzt​ 后，扩散头从噪声逐步恢复动作块。下面用标准噪声预测形式解释去噪训练：

xk=αˉkA+1−αˉkϵ,L=E∥ϵ−ϵψ(xk,zt,k)∥2.x_k=\sqrt{\bar\alpha_k}A+\sqrt{1-\bar\alpha_k}\epsilon,\qquad \mathcal L=\mathbb E\|\epsilon-\epsilon_\psi(x_k,z_t,k)\|^2.xk​=αˉk​​A+1−αˉk​​ϵ,L=E∥ϵ−ϵψ​(xk​,zt​,k)∥2.

kkk 是噪声级别，ϵ\epsilonϵ 是采样噪声，αˉk\bar\alpha_kαˉk​ 控制动作信息保留量。这是教学形式，部署调度应按模型配置实现。若把每次去噪都重新运行完整图像主干，会引入并非架构必需的计算开销。

普通均方误差回归容易把两种动作求平均。扩散头则学习条件分布中的多个区域。不过，多模态建模只是机制解释；是否更成功仍需机器人闭环实验验证。

3. 图像目标帮助使用无语言数据

训练时从轨迹未来抽取目标图像，并在语言和图像条件之间进行遮蔽。它让没有语言注释的示范仍然参与训练，而不是凭空生成动作监督。

目标图像还提供了语言没有表达的空间细节。“放到盘子里”未指定盘内位置，目标图像可能已经显示了目标姿态。因此两类条件的成功率差异，不应全部归因于语言理解差。

4. 数据混合也是方法的一部分

预训练选取具有图像及合适动作接口的数据，并调整不同来源的采样权重。夹爪语义也要统一：开合状态与“本步是否改变开合”的标签并不等价。相同数值若代表相反物理含义，更多数据反而会制造冲突。

附录对数据打乱的讨论很有价值。连续取一条长轨迹的许多相邻帧，会让一个 minibatch 的有效多样性很低；帧级交错和更大的缓冲区改变了模型实际看到的数据分布。

5. 下游微调的流程

预训练：
    从加权数据混合中取图像历史、任务和动作块
    屏蔽缺失传感器，随机选择语言或未来图像作为条件
    Transformer 生成动作读出表示
    对动作加噪，训练扩散头与共享策略参数
适配新机器人：
    保留主干，添加所需传感器编码器或新维度动作头
    用目标平台示范微调整个策略
部署：
    编码当前观测一次，在小动作头内迭代去噪
    执行动作块的前一部分，重新观察并生成下一块

“保留预训练权重”指初始化时无需丢弃主干，不等于训练时始终冻结主干。论文使用全策略微调，并比较了冻结部分参数的方案。

六、贡献、代价与失败情形

Octo 的新意集中在可适配策略系统与实证组合，而不是发明扩散模型或 Transformer。它把开源预训练策略变成能改输入、改输出的研究起点。

成本既包含上游示范采集，也包含数据清洗、物理接口统一和训练基础设施。下游“约五小时”是已有数据与模型后的训练成本，不包括机器人搭建和示范收集。

作者指出腕部相机、语言条件仍有短板，并联系到这两种模态在预训练中的覆盖比例。这是合理解释，但要证明因果关系，还需在相同总量下专门控制模态覆盖，而不是仅观察数据频率和性能同时偏低。

我的分析是，模块化更像允许模型继续学习的插座，而非通用控制知识的保证。新增力输入是否有用，取决于示范是否包含足够接触变化；新增 14 维动作头是否协调双臂，取决于目标数据是否展示了协同关系。

八、三个问题及答案

问题1：为什么可以新增动作头，却不能直接把旧动作值当新机器人的关节角？

答案：参数接口的可扩展性与物理语义不同。末端位移和关节角不是同一变量；新增头要通过目标示范学习映射。直接重新解释旧值会破坏单位、坐标和运动学关系。

问题2：扩散需要多次迭代，为什么不意味着图像 Transformer 也运行同样多次？

答案：图像和任务先编码成固定条件表示，去噪循环只在较小的动作头内使用这个表示。两部分计算可以分离，这也是动作分布表达力与推理成本之间的重要设计。

问题3：72% 对 20% 应怎样描述，才能避免夸大？

答案：按舍入均值是约 52 个百分点，或相对基线约提高 260%。更重要的是说明这是若干下游微调设置的平均，且预训练方使用了大量上游数据；它不表示每个机器人都提高相同比例，更不是零样本新技能的结果。
