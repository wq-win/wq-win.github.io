083｜Mamba：用选择性的状态压缩，重新挑战注意力架构

返回目录 · 发展时间线

论文：Albert Gu、Tri Dao，Mamba: Linear-Time Sequence Modeling with Selective State Spaces，2023。本文依据论文 v2的状态空间推导、选择机制、语言及合成实验、消融和效率附录；DNA、音频作为适用边界的补充证据。实现见官方代码。未独立训练模型或重测吞吐。

一分钟理解：记忆不必保存全部历史，但必须知道什么值得记

Transformer 保留历史 token 的 KV，当前问题可以直接访问这些位置。循环模型把历史压缩进固定大小状态，运行更省，却可能把重要信息与无关噪声一起冲淡。

Mamba 的核心不是简单恢复普通 RNN，而是让状态空间模型根据当前输入改变写入、保留和读取方式。遇到值得记忆的内容时写入，遇到噪声时尽量维持状态。它同时设计高效扫描实现，使这种输入相关的递推能够在 GPU 上训练。

作者希望兼顾选择能力和线性序列成本。实验支持所测语言规模上的竞争力，以及特定合成任务和其他模态的长序列能力；不能把这些结果解释为固定状态能无损保存任意长文本。

一句话：在长序列建模中，通过输入相关的状态更新与硬件友好的扫描，在不保存全部 KV 的条件下改善选择性记忆和效率，限制是有限状态压缩与任务、规模、实现相关的取舍。

五个前置概念

五个前置概念：状态空间模型通过隐状态传播序列信息；线性时不变表示动力学不依赖时刻或输入；离散化将连续系统转成逐步更新；并行扫描利用结合律求前缀复合；状态压缩以有限表示替代保存全部历史。

背景：固定卷积核为什么会错过内容

普通线性时不变 SSM 的递推是

ht=Aˉht−1+Bˉxt,yt=Cht.h_t=\bar A h_{t-1}+\bar Bx_t,\qquad y_t=Ch_t.ht​=Aˉht−1​+Bˉxt​,yt​=Cht​.

hth_tht​ 是状态，xtx_txt​ 是输入，yty_tyt​ 是输出；Aˉ\bar AAˉ 控制旧状态演化，Bˉ\bar BBˉ 控制写入，CCC 控制读出。这些矩阵不随位置或输入变化时，整个序列变换可写成固定卷积，因此能够使用高效卷积计算。

但固定间隔复制与选择性复制不同。前者可能只需“把 20 步以前的东西搬过来”，后者要求“记住带标记的字符，忽略中间数量不定的空白”。若动力学完全固定，就难以根据当前内容决定这一步是否应推进记忆。

Mamba 的论点是：状态压缩质量取决于选择能力。这个说法是模型设计动机，不是固定容量能够解决所有记忆任务的证明。与强化学习中的环境状态模型不同，这里的 SSM 是神经序列层；训练仍主要采用下一 token 预测。

方法：选择机制、扫描算法和网络块缺一不可

1. 让部分参数成为输入的函数

Mamba 将 Bt,Ct,ΔtB_t,C_t,\Delta_tBt​,Ct​,Δt​ 设为输入相关量，保留结构化的 AAA。典型离散化为

Aˉt=exp⁡(ΔtA),Bˉt=(ΔtA)−1(exp⁡(ΔtA)−I)ΔtBt.\bar A_t=\exp(\Delta_tA),\qquad \bar B_t=(\Delta_tA)^{-1}(\exp(\Delta_tA)-I)\Delta_tB_t.Aˉt​=exp(Δt​A),Bˉt​=(Δt​A)−1(exp(Δt​A)−I)Δt​Bt​.

然后用 ht=Aˉtht−1+Bˉtxth_t=\bar A_th_{t-1}+\bar B_tx_tht​=Aˉt​ht−1​+Bˉt​xt​ 更新。这里写的是论文用于解释的零阶保持离散化关系；实际实现会利用对角结构和融合计算，不能照字面为每个 token 做一般矩阵求逆。

Δt\Delta_tΔt​ 经 softplus 保持为正，可以理解为对当前输入的有效处理时长。稳定衰减的 AAA 下，较小 Δt\Delta_tΔt​ 更接近保留旧状态，较大值更强调当前信息。BtB_tBt​ 控制写入方向，CtC_tCt​ 控制读出。虽然递推对给定系数下的状态是线性的，但系数依赖输入，完整模型不再是线性时不变系统，也不再对应一个固定卷积核。

2. 一个能手算的门控联系

§3.5 定理 1 取一维状态、A=−1,B=1A=-1,B=1A=−1,B=1，并设 Δt=softplus⁡(ut)\Delta_t=\operatorname{softplus}(u_t)Δt​=softplus(ut​)，可得到

ht=(1−gt)ht−1+gtxt,gt=σ(ut).h_t=(1-g_t)h_{t-1}+g_tx_t,\qquad g_t=\sigma(u_t).ht​=(1−gt​)ht−1​+gt​xt​,gt​=σ(ut​).

原因是 e−softplus⁡(u)=1−σ(u)e^{-\operatorname{softplus}(u)}=1-\sigma(u)e−softplus(u)=1−σ(u)。这给出了门控循环与连续系统离散化之间的具体联系，而不是说完整 Mamba 就是一维平均器。真实层有多个通道、更高维状态和输入相关写读参数。

3. 失去卷积以后，用扫描恢复并行性

将一步递推写为仿射映射 ft(h)=at⊙h+btf_t(h)=a_t\odot h+b_tft​(h)=at​⊙h+bt​。两步复合仍是同类映射：

(a2,b2)∘(a1,b1)=(a2⊙a1, a2⊙b1+b2).(a_2,b_2)\circ(a_1,b_1) =(a_2\odot a_1,\ a_2\odot b_1+b_2).(a2​,b2​)∘(a1​,b1​)=(a2​⊙a1​, a2​⊙b1​+b2​).

函数复合满足结合律，所以训练时可以使用并行前缀扫描，而无需在 Python 中串行循环所有 token。输入相关系数并不破坏这个结合性，因为它们可由当前层的已知输入预先求出。

如果把每个位置的全部扩展状态写入显存，仍会有巨大的读写成本。论文将离散化和扫描融合，利用片上存储，并在反向传播时重算部分中间量。这是实现收益的重要来源；“复杂度是线性”不足以保证任意朴素代码都快。

4. 网络块还包含局部处理和门控

Mamba 块用输入投影、局部卷积、激活、选择性 SSM、另一分支的门控和输出投影组合，外层继续使用归一化与残差。所谓没有独立 MLP 块，不表示没有线性投影或非线性变换。

输入：序列 X，上一轮生成保存的状态（推理时）
对每个 Mamba 层：
    归一化并投影，形成主分支与门控分支
    主分支经过局部因果卷积和激活
    从主分支预测每位置的 B、C、正值 Delta
    对结构化 A 做离散化，得到递推系数
    训练：用融合并行扫描计算各位置输出
    生成：仅更新当前 SSM 状态和局部卷积状态
    将读出结果与门控分支结合，输出投影并加残差
用语言模型头预测下一 token，计算交叉熵
输出：预测分布；生成时保留固定尺寸的层状态

固定状态意味着其大小不随历史长度增长，但仍随层数、通道和状态维度增长；局部卷积也有缓存。它不是“推理无需内存”。

四组证据：选择有效，边界同样具体

证据一｜图 4、定理 1：改动确实进入了序列记忆机制。 相同 Mamba 外部块，内部 S4 的选择性复制准确率为 56.4，换成 S6 为 99.8；无门控外部块从 S4 的 18.3 到 S6 的 97.0。它支持内部选择机制的重要性，而非只靠多一个外围乘法门。定理给出特殊条件下的精确联系，实验则展示具体任务效果，二者证据性质不同。

证据二｜表 1：相近训练口径下有竞争力，但不是所有 Transformer。 Mamba-2.8B 平均下游准确率 63.3，Pythia-2.8B 为 59.1，差 4.2 个百分点；Pythia-6.9B 为 61.7。它支持在这批开放模型和任务上的参数效率。不同模型训练配方并不完全相同，也没有在这里验证几十或数百 B 参数的同样优势。

证据三｜表 2、图 13：参数选择协同改善语言建模。 Mamba 块使用实数 S4 时困惑度 10.56，选择性 S6 为 8.69；另一组选择参数消融中，全固定为 10.93，仅 Δ\DeltaΔ 选择为 9.81，三项都选择为 8.71。支持选择机制不仅对合成题有效；两组数值属于不同配置，不应拼成单一逐步训练轨迹。

证据四｜图 12 与附录 E.5：速度取决于比较层级。 作者报告 4—5 倍生成吞吐，主要收益之一是没有增长的 KV，能容纳更大批量。核心扫描则与 FlashAttention-2 比较，端到端生成基线采用 Hugging Face 的标准 GPT-3 架构实现，不能说完整系统全面快于所有优化推理引擎。表 7 的训练显存中，批量 32 的 125M Mamba 为 38.2GB，优化 Transformer 为 34.5GB，Mamba 并非处处更省训练显存。

贡献、代价与一个手算例子

贡献是将输入选择性与高效扫描结合，使循环压缩架构在语言任务上具有实际竞争力。理论门控联系解释了参数作用，消融支持机制选择，系统测量说明实现可行；它们共同构成贡献，而非一张吞吐图独立证明架构全面更好。

固定状态需要丢弃信息。如果未来问题需要此前被过滤的细节，模型不能像完整 KV 一样直接回看原位置。选择性也不总有利：附录 E.4.1 图 18 的连续音频消融中，S6 会损害某些配置，匹配平滑信号的时不变归纳偏置反而更好。作者也明确指出更大语言模型规模仍待验证。

自构例子。 用前面的一维门控式，初始 h=0h=0h=0，需记的数值为 7，设 g=1g=1g=1，则状态变 7。后面来了三个噪声值，若都取 g=0g=0g=0，状态仍是 7；固定 g=0.5g=0.5g=0.5 则会不断混入噪声。这解释了选择的作用，但一维状态无法无损保存任意多个独立数字；完整模型需要更多状态和训练学习如何分配它们。

自测：能否从公式看出选择和压缩

1. 为什么让 B,C,ΔB,C,\DeltaB,C,Δ 依赖输入后不能再用一个固定卷积核？

答案：固定核要求同一相对距离具有相同线性响应；输入相关参数使不同内容、不同位置的写入和传播系数变化。同样间隔的 token 可以被保留或忽略，因此不再是时不变卷积。给定系数后的仿射递推仍满足可结合的复合，允许扫描。

2. “固定大小状态”是否意味着无限长度无损记忆？

答案：不是。它表示计算缓存的尺寸不随历史长度增长，代价正是压缩。有限精度和容量不能保留任意多独立细节。百万长度合成题成功说明模型在该任务结构下保住了必要信息，不能推出任意长文问答都可靠。

3. 论文的 5 倍速度应怎样限定？

答案：应注明 A100、提示和生成长度、批量扫描、Transformer 实现以及吞吐指标；其中还包含未训练大模型的计时。它不是单请求所有延迟的统一倍数，更不是模型准确率提升。核心扫描、端到端生成与训练显存属于不同实验，必须分开比较。
