075｜DPO：把奖励模型藏进概率比，直接学习偏好

返回目录 · 发展时间线

论文：Rafael Rafailov 等，Direct Preference Optimization: Your Language Model is Secretly a Reward Model，首次公开于2023年。论文、正文 v3。本文以2024年更新的 v3 方法、理论、实验和实现附录为依据；没有独立复现训练。DPO 属于直接偏好优化，不能只因名称带“策略优化”就把它等同于 PPO 式在线强化学习。

一分钟理解：能不能省掉“先打分，再强化学习”？

给定同一个问题，人类觉得回答A比B好。传统 RLHF 通常先训练一个模型，学会给A更高的奖励；再让语言模型生成新回答，用奖励指导 PPO 更新。两个训练阶段加上采样、参考模型和价值估计，让实现和调参都比较复杂。

DPO 发现，在常用的偏好模型和 KL 正则目标下，奖励可以写成“当前策略相对参考策略的对数概率比”。把这个式子代入偏好损失，就能直接训练语言模型，不必先拟合一个独立奖励网络，也不必在每次更新时生成新回答。

摘要实验中，GPT-4 评委给 DPO 对人类参考摘要的胜率约61%，PPO约57%；人类直接比较两者时，指定采样条件下58%偏好DPO。这支持该实现的有效性，不能证明所有任务中DPO都优于经过充分调优的PPO。

一句话总结：在已有成对偏好数据的语言生成任务中，通过重参数化 KL 正则奖励目标，直接优化回答概率比，简化偏好学习并改善所测任务表现，限制是数据覆盖、偏好假设和分布外泛化仍然重要。

五个前置概念

五个前置概念：成对偏好只确定两项相对排序；参考策略定义改变的基准；KL散度度量策略分布偏离；配分函数把未归一分数变成概率；奖励等价类表示只差问题相关常数的奖励具有相同偏好和最优策略。

背景：偏好学习并不直接告诉你绝对奖励

训练数据为 (x,yw,yl)(x,y_w,y_l)(x,yw​,yl​)：问题 xxx、被偏好的回答 ywy_wyw​、较不被偏好的回答 yly_lyl​。这不意味着 ywy_wyw​ 完美，也不意味着 yly_lyl​ 完全错误；只表示在这一对中，标注者更喜欢前者。

Bradley–Terry 模型把偏好概率写成奖励差的 sigmoid：

P(yw≻yl∣x)=σ(r(x,yw)−r(x,yl)).P(y_w\succ y_l\mid x)=\sigma(r(x,y_w)-r(x,y_l)).P(yw​≻yl​∣x)=σ(r(x,yw​)−r(x,yl​)).

这种模型假设偏好可由标量效用差表达。现实中的偏好冲突、群体差异和非传递选择不一定完全符合它。论文以此作为建模前提，而不是证明人类偏好天然服从该形式。

语言模型的策略 π(y∣x)\pi(y\mid x)π(y∣x) 是整段回答的条件分布。参考模型 πref\pi_{ref}πref​ 通常来自 SFT，用来定义模型改变的起点。本文的经典离线设定不需要环境交互；生成过程可以看作逐token决策，但训练利用的是固定完成序列的似然。

方法推导：归一化项怎样消失？

从常见 RLHF 目标出发：

max⁡π  Ey∼π(⋅∣x)[r(x,y)]−βDKL(π(⋅∣x)∥πref(⋅∣x)).\max_\pi\;\mathbb E_{y\sim\pi(\cdot|x)}[r(x,y)] -\beta D_{KL}(\pi(\cdot|x)\|\pi_{ref}(\cdot|x)).πmax​Ey∼π(⋅∣x)​[r(x,y)]−βDKL​(π(⋅∣x)∥πref​(⋅∣x)).

β>0\beta>0β>0 控制偏离参考策略的代价。给定奖励、允许优化整个策略分布时，最优解满足：

πr(y∣x)=πref(y∣x)er(x,y)/βZ(x),r(x,y)=βlog⁡πr(y∣x)πref(y∣x)+βlog⁡Z(x).\pi_r(y\mid x)=\frac{\pi_{ref}(y\mid x)e^{r(x,y)/\beta}}{Z(x)},\qquad r(x,y)=\beta\log\frac{\pi_r(y\mid x)}{\pi_{ref}(y\mid x)}+\beta\log Z(x).πr​(y∣x)=Z(x)πref​(y∣x)er(x,y)/β​,r(x,y)=βlogπref​(y∣x)πr​(y∣x)​+βlogZ(x).

Z(x)Z(x)Z(x) 对同一个问题的所有回答相同。在比较 ywy_wyw​ 与 yly_lyl​ 时，两个 βlog⁡Z(x)\beta\log Z(x)βlogZ(x) 抵消。因此只需要概率比，不必对巨大回答空间求和。

定义单个偏好对的 margin：

Δθ=β[log⁡πθ(yw∣x)πref(yw∣x)−log⁡πθ(yl∣x)πref(yl∣x)],LDPO=−EDlog⁡σ(Δθ).\Delta_\theta=\beta\left[ \log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}- \log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}\right],\qquad \mathcal L_{DPO}=-\mathbb E_D\log\sigma(\Delta_\theta).Δθ​=β[logπref​(yw​∣x)πθ​(yw​∣x)​−logπref​(yl​∣x)πθ​(yl​∣x)​],LDPO​=−ED​logσ(Δθ​).

这就是论文式7。它不是“只提高好答案概率”，而是增加相对于参考模型的成对概率优势。每条回答的 log probability 是回答 token 对数概率之和，不能随手换成平均每token概率却仍宣称实现原始目标。

梯度包含权重 βσ(−Δθ)\beta\sigma(-\Delta_\theta)βσ(−Δθ​)：已经很好地区分的偏好对更新较小，排序错误的偏好对更新较大。它与朴素地无休止降低坏答案似然不同。由于参数共享和归一化，不能把单步梯度直觉提升为“每个赢家的绝对概率在实际训练中都必然增加”。

输入：偏好对 D、参考策略 ref、初始化策略 policy、β
freeze ref
for prompts, chosen, rejected in D:
    pw = sum_answer_token_logprobs(policy, prompts, chosen)
    pl = sum_answer_token_logprobs(policy, prompts, rejected)
    rw = sum_answer_token_logprobs(ref, prompts, chosen)  # no gradient
    rl = sum_answer_token_logprobs(ref, prompts, rejected)
    margin = β * ((pw - pl) - (rw - rl))
    loss = mean(-logsigmoid(margin))
    update policy parameters
输出：经过偏好学习的语言模型

提示和 padding 必须正确掩码，参考与当前模型的分词、聊天格式必须一致。参考 log probability 可在数据与参考模型固定时预先计算；这是实现上的优化，不改变目标。训练循环没有在线采样，并不意味着构建偏好数据从未生成过回答。

理论究竟保证什么？

§5的引理1、引理2说明：给同一问题的所有回答奖励加同一个函数 f(x)f(x)f(x)，既不改变 Bradley–Terry 偏好，也不改变 KL 正则下的最优策略。定理1利用这个奖励等价类，解释为什么可以选择对数概率比形式而不损失相应表示能力。

附录的命题还要求参考分布在相应回答上为正等条件。理论是关于分布、奖励和可表示性的关系，不是神经网络非凸训练的全局收敛定理。有限数据未覆盖的回答、参数化模型容量不足、标签噪声和优化误差，都可能使实际结果偏离理想最优解。

此外，DPO损失中没有再显式逐批计算一个完整KL惩罚项，但参考策略与 β\betaβ 已进入重参数化。对固定奖励的解析最优策略而言，较大 β\betaβ 更保守；对有限数据训练过程，不能仅看损失中 β\betaβ 乘在梯度外面，就推断实测KL一定如何变化。

证据一：图2左，奖励—KL前沿。 DPO在该情感实验中以较低偏离取得更高分类器奖励，甚至优于直接获得分类器奖励的 PPO-GT 配置。它支持这组实现中优化方式有效，不证明分类器奖励与电影评论真实质量完全一致，也不证明PPO在理论上达不到同一前沿。

证据二：图2右与§6.2，摘要。 温度0时 DPO 对参考摘要胜率约61%，PPO约57%，绝对差约4个百分点。分数来自GPT-4评判，而非逐事实验证。不同温度下的曲线还显示该配置中的稳健性差异，不能忽略采样设置再比较一个最高点。

证据三：表2，人类与模型评委。 DPO温度0.25对PPO温度0，人类胜率58%；GPT-4简单提示为47%，强调简洁后为54%。评委提示会改变排名判断，单个自动分数不能作为无条件的真值。逐例一致率与人际一致率相近，是有效性支持，但不是所有任务都可靠的证明。

贡献、代价与局限

DPO 的核心贡献是理论驱动的变量替换：把奖励学习与策略优化联系到一个可直接监督训练的损失。省掉独立奖励训练和在线采样循环，降低了工程复杂度，但仍需要两条回答的前向、策略反向、参考概率和高质量偏好标签。

作者将分布外泛化、过度优化和更大模型验证列为开放问题。进一步分析还包括：离线数据可能与更新后策略分布不匹配；更长、更讨好或格式更统一的答案可能获得偏好，而不一定更正确；仅优化相对优势可能把概率质量转移到未被比较的回答上。没有显式奖励网络，不意味着没有奖励投机或评价漏洞。

自测与答案

1. DPO 不训练独立奖励网络，为什么仍然可以谈“隐式奖励”？

答案：当前策略相对参考策略的对数概率比乘β可以表示一个奖励等价类的成员。它参与成对偏好概率，并对应KL正则目标的策略。但这个值不是独立的事实正确性评分，也不能跨任意参考模型直接比较。

2. 配分函数为什么能消掉？如果两个回答来自不同问题还可以直接抵消吗？

答案：同一个问题的两个奖励都有相同的βlogZ(x)，相减为零。不同问题通常有不同Z，因此不能直接利用同样推导消掉。原始DPO数据对必须共享提示条件。

3. “DPO 与 RLHF 目标等价”是否说明不用探索也能学到所有最优回答？

答案：不能。等价推导说明在假设下如何连接奖励和最优策略，数据没有覆盖的区域仍然缺少约束，有限模型也未必达到全局解。应检查偏好覆盖、更新后生成分布与真实评价，而不是把公式当作离线数据充分性的证明。
