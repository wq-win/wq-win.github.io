073｜GQA：查询头可以很多，历史记忆不必人手一份

返回目录 · 发展时间线

论文：Joshua Ainslie 等，GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints，2023。论文、正文 v3、论文采用的 Flaxformer。本文核对全部方法与实验正文及训练稳定性附录；没有独立运行 TPU 基准。原文主实验是 T5 编码器—解码器模型，不把后来 decoder-only 模型的采用情况当作这篇论文的实验。

一分钟理解：生成一个词，也要搬动很多旧信息

语言模型逐 token 生成时，会把历史 token 的 key 和 value 缓存下来。下一步不必重新计算历史表示，但仍需要读取它们。如果每个注意力头都有独立的历史缓存，长序列和大批量下的存储与搬运成本会很高。

MQA 让所有查询头共享一组 key/value，可以减少缓存，却可能牺牲模型能力。GQA 在两端之间折中：保留多个查询头，把它们分组，同组共享 key/value。作者还提出把已有 MHA 模型转换后继续预训练，避免为新的结构从头训练一遍。

表1中 T5-XXL 的 GQA-8 平均任务得分47.1，接近 MHA 的47.2；论文规定的推理时间为0.28秒，对比1.51秒。这里的时间是按样本和 TPU 芯片归一的基准，不能直接当作任意 GPU 单用户服务的首 token 延迟。

一句话总结：在自回归推理受 KV 缓存搬运影响的场景下，通过分组共享 key/value 并对转换后的模型继续训练，改善质量与推理成本的折中，限制是结构变化需要适配，实际速度取决于硬件、批量和序列长度。

五个前置概念

五个概念：KV cache存储历史键值避免重复计算；query头决定每次如何读取历史；带宽瓶颈表示时间主要花在搬数据；继续预训练让已有模型适应结构或数据变化；吞吐与延迟分别衡量单位时间总工作量与单次请求等待时间。

背景：MHA、MQA 和 GQA 到底共享什么？

设查询头数为 HHH，KV 头数为 GGG。MHA 对应 G=HG=HG=H；MQA 对应 G=1G=1G=1；GQA 在两者之间选择。每个查询头仍然有自己的 query 投影，所以共享 KV 不意味着组内所有头产生相同的注意力分布。

对于查询头 hhh，令 g(h)g(h)g(h) 为所属组，其输出为：

Oh=softmax⁡(QhKg(h)⊤dk+M)Vg(h).O_h=\operatorname{softmax}\left(\frac{Q_hK_{g(h)}^\top}{\sqrt{d_k}}+M\right)V_{g(h)}.Oh​=softmax(dk​​Qh​Kg(h)⊤​​+M)Vg(h)​.

dkd_kdk​ 是头维度，MMM 是掩码；自回归自注意力使用因果限制。不同 QhQ_hQh​ 可以针对同一组历史键提出不同查询，因此仍有多种“读取视角”，只是历史信息的写入表示被共享了。

本文不是删掉历史 token，也不缩短上下文窗口。缓存仍然覆盖相同序列，只是每个位置存储的 KV 头更少。它也不同于 FlashAttention：后者主要改变注意力计算与数据搬运组织，GQA 改变参数共享和表示容量。

需要注意原文只对 decoder 自注意力和交叉注意力应用 MQA/GQA，encoder 自注意力保持 MHA。编码器并行处理输入，其性能瓶颈与逐 token 解码不完全相同。

方法：分组平均不是精确等价变换

从已有 MHA 检查点转换时，每组的 key/value 投影取组内平均：

WK(g)=1∣Ig∣∑h∈IgWK(h),WV(g)=1∣Ig∣∑h∈IgWV(h).W_K^{(g)}=\frac{1}{|I_g|}\sum_{h\in I_g}W_K^{(h)},\qquad W_V^{(g)}=\frac{1}{|I_g|}\sum_{h\in I_g}W_V^{(h)}.WK(g)​=∣Ig​∣1​h∈Ig​∑​WK(h)​,WV(g)​=∣Ig​∣1​h∈Ig​∑​WV(h)​.

IgI_gIg​ 是该组的原始头集合。query 和输出投影按转换方案保留。平均值利用全部原始头的信息，是一个初始化选择；因为 softmax 非线性，平均投影后的注意力不等于原先多个注意力输出的平均，所以不能声称这是无损压缩。

随后按原始预训练配方继续训练 α\alphaα 比例的步数。主实验取 α=0.05\alpha=0.05α=0.05，即原预训练步数的5%。没有新的专用 GQA 损失；沿用 T5 的预训练目标，让各层共同适应共享结构。

输入：已训练 MHA 检查点、组数 G、继续训练比例 α
for decoder attention layer:
    divide H query heads into G groups
    for each group:
        shared_K = mean(original_K_projections_in_group)
        shared_V = mean(original_V_projections_in_group)
    retain query projections and compatible output projection
continue pretraining with original objective and data recipe
finetune on each downstream task
decode with G KV heads and H query heads
输出：经适配的 GQA 模型及其质量/时间测量

数学目标是原任务损失；机制是共享投影与继续训练；指标是下游分数、稳定性和推理时间。“用5%算力”指利用已有模型后的增量适配，不是从随机初始化得到同等模型只需原训练成本的5%。

缓存为什么会变小，为什么速度不按比例增长？

对于仅考虑 decoder 自注意力的简化计算，设层数 LLL、批量 BBB、历史长度 SSS、每个缓存元素 qqq 字节，KV 存储量近似为：

Bytes⁡KV=2LBSGdkq.\operatorname{Bytes}_{KV}=2LBSGd_kq.BytesKV​=2LBSGdk​q.

前面的2分别对应 key 和 value。在其他条件相同时，GQA 相对 MHA 的缓存比为 G/HG/HG/H。这是缓存项的关系，不是总显存或总时间的关系；权重、激活、临时工作区和交叉注意力缓存都可能占用资源。

此外，查询头数量没有减少，很多注意力乘法仍然存在。速度改善主要来自内存流量和更合适的并行布局。原文还讨论了 MQA 的单个 KV 头在多分片上复制的浪费；组数适当增加时，逻辑缓存增加不一定按同样比例转化为物理通信和存储增加。

结果：四条证据与一个尚未解释的现象

证据一：表1与图3，主要折中。 MHA-XXL、MQA-XXL、GQA-8-XXL 的平均分分别47.2、46.6、47.1；时间1.51、0.24、0.28秒。按表内时间自行计算，MHA/GQA约为5.39倍；这个比值仅适用于该测量。GQA 比 MQA 略慢，但平均分更接近 MHA。

证据二：表1的分任务结果。 GQA 的 PubMed 为47.7，对比 MHA47.5；TriviaQA为81.6，对比81.9；CNN为43.5，对比43.8。因此“质量接近”不等于每项严格无损，也不能从略高的单项分数推出新结构本身更准确，尤其缺少完整不确定性区间时。

证据三：图4与图5，转换和恢复。 平均原始头的初始化优于保留单头和随机初始化；5%继续训练帮助 MQA 与 GQA，增加到10%的收益递减。这支持“保留已有表示再适配”的路线；图中趋势不能证明5%是其他模型、数据或组数上的最优比例。

证据四：图6，组数。 在输入2048、输出512的配置下，从1组增加到8组的时间开销较小，接近 MHA 时增加更明显。8组是作者选择的实用折中，不能因为一个后来的模型也使用8个 KV 头，就认为已经得到普适理论常数。

补充证据：附录A。 从头训练的多个 MQA T5-Large 出现损失尖峰，在长输入任务微调中发散；转换后 MQA 更稳定但仍有方差，GQA 看起来稳定。作者没有继续定位根因。因此可以报告观察到的稳定性差异，不能自行解释为“平均头一定消除了某种梯度病态”。

贡献与局限：一条可复用的系统设计轴

真正的新意是提供 MHA 与 MQA 之间可调的结构轴，并给出从已有检查点转换的训练配方。它让部署约束能够进入模型架构设计，而不必在完全独立的 KV 与完全共享的 KV 之间二选一。

作者承认主实验仅覆盖编码器—解码器结构，没有与从头训练的 XXL GQA 做等预算比较，也承认 ROUGE 不能全面评价生成质量。因此论文没有回答“同样总训练预算下，先训练MHA再转换，是否优于直接训练GQA”。

进一步分析还包括：KV压缩对长序列大批量可能更有价值，但当权重搬运或计算成为主瓶颈时，收益会减弱；转换需要原预训练数据或足够匹配的替代数据；缓存省下来的显存可能用于更大批量，改变延迟与吞吐的折中。质量、总显存和速度应该分别测量。

自测与答案

1. 同组查询头共享 K 和 V，为什么输出仍然可以不同？

答案：每个头的 Q 仍不同，因而与相同 K 计算出的分数和 softmax 权重不同，可以从同一组 V 中读出不同组合。共享的是历史表示，不是查询方式，也不是最终注意力权重。

2. 把32个 KV 头改为8个，是否等于模型快4倍、总显存少75%？

答案：只在相同条件下，自注意力 KV 缓存项缩小到四分之一。模型权重和其他工作区并未同比缩小，查询相关运算也仍存在。必须测量具体瓶颈，才能预测端到端收益。

3. 为什么不能直接平均头后发布，并宣称和原模型等价？

答案：注意力包含非线性，平均投影不能保持原输出。需要测量转换后的质量并进行适配训练；原文图5也展示继续训练的作用。即便均值初始化优于其他方案，也只是好的起点，不是等价性证明。
