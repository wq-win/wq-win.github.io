返回目录 · 发展时间线

论文：Leo Gao、Tom Dupré la Tour 等，Scaling and evaluating sparse autoencoders，2024。依据原文 v1的方法、评估、规模实验和优化附录；代码见官方仓库。GPT-4 激活与完整底层训练资料并未全部开放，因此开放模型部分和闭源模型部分的可复现范围不同。

一分钟理解：给复杂激活找一本稀疏词典

语言模型的一个神经元可能同时响应多种不相关现象，一个概念也可能分散在很多神经元中。直接看单个坐标，常常得不到清晰解释。稀疏自编码器 SAE 尝试用一套更宽的特征字典重建原始激活，但要求每次只使用其中少量特征。

这篇论文关心怎样把字典做大、怎样避免大量特征永远不激活，以及怎样判断学出的特征是否真正有用。作者使用 TopK 直接规定每个输入激活多少个潜变量，并给长期不活跃的变量增加辅助训练信号。

最大实验在 GPT-4 激活上训练约 1600 万潜变量的 SAE，使用 400 亿 token。研究的意义不仅是尺寸：它把重建误差之外的行为保真、可解释性和干预效果纳入评估。

一句话：在固定语言模型的激活分析中，通过 TopK 稀疏编码、死亡特征恢复与多维评估，获得更可扩展的特征分解，代价是巨大的字典训练成本，以及“可读特征”仍不等于完整机制解释。

五个前置概念

五个前置概念：残差流是多层不断读写的表示通道；字典学习用可复用方向组合表达数据；稀疏度 L0L_0L0​统计非零项数量；探针测量表示是否携带某种信息；消融干预主动改变内部量并观察输出变化。

背景：为什么普通自编码器还不够

输入 x∈Rdx\in\mathbb R^dx∈Rd 是语言模型某层的激活，SAE 将它编码成 nnn 维向量 zzz，通常 nnn 大于 ddd，再线性解码为 x^\hat xx^。如果没有约束，只需要复制输入就可以重建，未必发现任何有意义结构。

稀疏约束让模型每次只能使用少量字典方向，从而鼓励不同输入共享可复用组件。这个动机来自“特征可能叠加在同一个表示空间”的假设，不是所有真实语义都严格稀疏、线性可分的证明。

被解释的语言模型在此固定。SAE 的训练是激活上的无监督重建，不是让 GPT-4 重新学习语言，也不是 RLHF。论文不优化模型回答的奖励，而是学习一个用于观察和干预内部表示的分析工具。

必须区分两个数量：nnn 是字典总宽度，kkk 是单个输入保留的潜变量数。增加 nnn 扩大可选字典；增加 kkk 放宽每次重建的信息通道。这两种扩展不能混成“更多特征一定更可解释”。

方法：把稀疏度从间接惩罚改成直接选择

ReLU 基线为什么会缩小激活

传统 SAE 使用：

z=ReLU⁡(We(x−b)+be),x^=Wdz+b,z=\operatorname{ReLU}(W_e(x-b)+b_e),\qquad \hat x=W_dz+b,z=ReLU(We​(x−b)+be​),x^=Wd​z+b,

L=∥x−x^∥22+λ∥z∥1.L=\|x-\hat x\|_2^2+\lambda\|z\|_1.L=∥x−x^∥22​+λ∥z∥1​.

重建项希望系数足够大以表达输入；L1L_1L1​ 项又持续把所有非零系数往零推。这不仅选择哪些特征活跃，还会扭曲活跃特征的幅值。调 λ\lambdaλ 也无法预先确定最终恰好有多少个非零潜变量。

TopK 保留竞争赢家，训练重建幅值

论文改用：

u=We(x−b),z=TopK⁡k(u),x^=Wdz+b.u=W_e(x-b),\qquad z=\operatorname{TopK}_k(u),\qquad \hat x=W_dz+b.u=We​(x−b),z=TopKk​(u),x^=Wd​z+b.

主损失仅为平方重建误差。TopK 选数值最大的 kkk 项，不是绝对值最大的 kkk 项；代码还使用 ReLU 保证非负，因此严格说是至多 kkk 个非零。原文指出合理 kkk 下被选项几乎总为正，通常表现为恰好 kkk 个。

选择集合随输入变化。反向传播更新被选中的路径；没有选中的方向可能长期缺乏梯度。因此直接控制稀疏度解决了一个问题，也带来特征竞争和死亡问题。

让沉默特征学习“剩下没有解释的部分”

作者将编码器方向初始化为解码器的转置方向，训练后两者并不永久绑定。对于很久没有激活的潜变量，从中挑出一组候选，尝试解释当前主重建残差 e=x−x^e=x-\hat xe=x−x^：

Laux=∥e−Wdzdead∥22,Ltotal=Lrecon+αLaux.L_{\rm aux}=\|e-W_dz_{\rm dead}\|_2^2,\qquad L_{\rm total}=L_{\rm recon}+\alpha L_{\rm aux}.Laux​=∥e−Wd​zdead​∥22​,Ltotal​=Lrecon​+αLaux​.

这给尚未进入主 TopK 的方向一个学习入口。典型 α=1/32\alpha=1/32α=1/32，辅助激活数按模型宽度选择；主 kkk 和辅助 kauxk_{\rm aux}kaux​ 不能混为一谈。所谓死亡也只是操作性定义：例如连续 1000 万 token 未激活，不表示这个特征在所有可能输入上永远无用。

输入：固定语言模型、选定层、文本、字典宽度 n、稀疏度 k
提取所选层激活，按论文方式去均值并归一化

for 激活批次:
    u = encoder(x - pre_bias)
    z = 非负 TopK(u, k)

结果：怎样避免“解释性幻觉”

证据一：图 2、图 5，TopK 改善重建与行为保真。 固定字典宽度或固定活跃数的曲线比较中，TopK 优于 ReLU 的前沿，并且在相同 MSE 下也可能有更小的下游损失。后一个观察说明误差落在哪些方向很重要，不能仅凭平均欧氏误差判断行为是否保存。

证据二：图 15、§2.4，死亡特征并非不可避免。 绑定方向初始化与 AuxK 组合显著减少沉默特征；最大 16M SAE 仍有约 7% 死亡。它支持训练方案更能利用字典容量，但没有说明每个活跃方向都是独立、自然或有用的语义单位。

证据三：§4.1，高保真百分数可能让人过度乐观。 16M SAE 相对“把激活清零”的损失恢复指标达到 98.2%；可是将其重建放回 GPT-4 后，语言损失只对应作者规模曲线中约 10% 预训练计算量模型的水平。后者不是删除了 90% 知识的直接测量，而是另一种损失标尺；两者共同说明糟糕的零基线会把恢复率抬得很好看。

证据四：图 6–8、图 24，解释必须检查误报。 N2G 在相近稀疏度下，TopK 的召回相对 ReLU 超过 1.5 倍，精确率略低但超过其 0.9 倍。只看被挑选的强激活样本容易给出过宽解释；精确率要求解释预测会激活的地方也真的激活。规则解释重建后的语言损失进一步检验这些可读部分覆盖多少行为。

证据五：图 10，测试时随意增大 k 可能反而变差。 TopK 在训练用的稀疏度附近工作较好，增加过多潜变量会让 MSE 恶化。未入选的系数不是训练好的残差信息，不能假设“保留更多数字必然更准确”。论文的 Multi-TopK 探索缓解了这种特定稀疏度适应。

贡献、代价与局限

TopK 稀疏自编码器并非此文首次提出，真正贡献是将它发展成能够大规模训练的配方，并提出更有区分力的质量评估。论文还给出字典宽度、稀疏度、被解释模型规模与重建误差的经验关系；这些是拟合规律，不是无限扩展时必然成立的定理。

低 MSE 和少量非零项仍不足以保证语义解释。极端宽的字典可以给几乎每个输入分配一个专用方向，重建很好却不形成可复用概念。作者在 §4 明确讨论这一退化情况。

单潜变量探针只证明某个标签可从该方向读出，不证明模型决策因果依赖该标签。消融提供更直接的干预证据，但人为删掉一个字典方向可能产生离开自然激活分布的状态，仍需结合更细的任务实验。

解释器也有偏好。N2G 擅长局部 token 模式，不擅长长距离或抽象条件。因此解释得差可能来自 SAE 特征复杂，也可能来自解释语言太弱。上下文仅 64 token 更限制了对长程功能的结论。

最后，固定 kkk 强制简单 token 和复杂 token 使用相似数量的特征，不一定符合真实计算的变动复杂度；而放大 kkk 又可能产生稠密、难解释方向。这是需要通过应用目标选择的取舍，不能用单一排行榜分数解决。

一个自构例子：重建、命名和因果各问一件事

设一段代码激活可以写成“Python 语法方向”加“字符串内部方向”。一个神经元混合了两种信号，看它的高激活例子会觉得主题杂乱；SAE 可能把它们分成两个稀疏方向。

现在给第二个方向命名为“字符串”。若它实际上只在双引号字符串的结尾激活，宽泛命名就会对单引号、字符串开头产生大量误报。漂亮的示例不能证明解释正确。

再把该方向删掉，若闭合引号的概率下降，这是行为影响证据；但还需要检查别的 token、不同输入和误差补偿，才能接近“它承担闭合字符串计算”的机制解释。

自测：能否克制地解释一个特征

1. 把 n 从十万增到一百万，与把 k 从 32 增到 320，有什么不同？

前者扩大可选择的字典，但每次仍只用少数方向；后者允许单个输入通过更多信息，通常更容易重建，却可能减弱稀疏约束和可读性。比较字典质量应固定或明确报告两者，而不能把重建误差下降直接视为解释更好。

2. 为什么 98.2% 的损失恢复率仍不足以宣布几乎完全解释 GPT-4？

它依赖把激活清零这个非常差的基线，只表示相对该破坏性操作恢复了大部分损失。剩余误差仍可能损害重要行为，而且可重建的方向不一定都有正确解释。还需原模型下游损失差、解释覆盖率、误报和因果实验。

3. 一个潜变量能够高准确率预测“负面情绪”，是否证明模型用它判断情绪？

不能。它可能与负面情绪共同变化，但不是模型实际依赖的计算变量。应在匹配输入条件下干预这个方向，检查情绪相关输出是否按预期变化，同时排除一般激活破坏及其他语言行为变化。探针是信息存在证据，干预和机制追踪才进一步检验使用方式。
