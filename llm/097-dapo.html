097｜DAPO：让长推理强化学习真正训练起来的四处修改

返回目录 · 发展时间线

论文：Yu 等，DAPO: An Open-Source LLM Reinforcement Learning System at Scale，2025。原文 · 正文 v1 · 作者项目页 · 训练框架。以下依据 v1 的公式、算法、训练动态和主表；没有独立复现训练，后续版本结果不混入本文。

一、一分钟理解

同样写着 GRPO，两个训练程序可能得到很不一样的模型。原因不一定在大公式：如果一批题全部答对或全部答错，就没有组内比较信号；如果长答案每个 token 的梯度被过度稀释，重复文本可能难以抑制；如果答案只是被长度上限截断，却被当成数学错误惩罚，奖励也会混入噪声。

DAPO 针对这些问题调整裁剪上下界、动态筛选有效题组、采用 token 级损失平均，并改进超长回答处理。在 Qwen2.5-32B 基础模型上，报告的 AIME 2024 平均正确率从朴素 GRPO 的 30 提高到 50。

一句话总结：在可验证数学任务的长推理 RL 中，通过修改更新约束、采样分布、损失权重和长度奖励，改善训练效果与稳定性，代价是额外采样以及对任务、验证器和预算的依赖。

五个前置概念

五个前置概念：策略熵 描述输出分布的分散程度；重要性比率 比较新旧策略对已采动作的概率；组相对优势 使用同题候选作基线；损失归约 决定不同样本与 token 的权重；奖励塑形 在任务结果之外加入辅助反馈。

二、问题设定与瓶颈

这是在线、无模型、单语言策略的强化学习。状态是问题与已生成前缀，动作是 token，回答结束或达到上限后获得结果奖励。作者从 Qwen2.5-32B 基础模型出发，使用约 17K 道整理后的数学题。

数据来源包括 AoPS 与竞赛题。作者将答案改成整数形式，以减少表达式解析与等价判断的错误。例如把最终形式为分式或根式的题改成询问若干系数之和。这能简化验收，但改题是否保留唯一解、形式约束是否充分，仍需检查；整数奖励不等于没有数据错误。

正确答案奖励为 1，错误为 -1。组内标准化后，关注的是同题不同尝试的相对表现。完整方法去掉参考策略 KL 惩罚，允许较大行为变化；这个选择适用于作者的数学实验，不是对通用偏好训练中 KL 作用的普遍否定。

三、四项修改分别改变什么

1. 非对称裁剪：给成功的低概率动作多一点空间

定义 token 概率比 ρi,t=πθ(oi,t∣q,oi,<t)/πold(oi,t∣q,oi,<t)\rho_{i,t}=\pi_\theta(o_{i,t}|q,o_{i,<t})/\pi_{old}(o_{i,t}|q,o_{i,<t})ρi,t​=πθ​(oi,t​∣q,oi,<t​)/πold​(oi,t​∣q,oi,<t​)。DAPO 将裁剪区间改成 [1−ϵlow,1+ϵhigh][1-\epsilon_{low},1+\epsilon_{high}][1−ϵlow​,1+ϵhigh​]，实验用 ϵlow=0.2\epsilon_{low}=0.2ϵlow​=0.2、ϵhigh=0.28\epsilon_{high}=0.28ϵhigh​=0.28。

对于正优势 token，较高上界让提高其概率的目标在更大区间继续起作用。论文用 0.01 与 0.9 的旧概率说明相对裁剪对小概率动作的绝对增量更小。必须补充：PPO 裁剪约束的是替代目标，不是参数更新后的概率硬边界；0.9 乘 1.2 得到 1.08 也不是一个合法的新概率。

2. 动态采样：补足有比较信号的题组

每题采样 GGG 个回答，若正确数为零或 GGG，该题组被排除，继续采样直到有效批次填满。若标准化奖励全相同，常规实现中的优势没有有效比较信号；保留足够多混合成败的题，能避免批次里真正参与更新的样本不断变少。

这不是“删除所有答对答案”。被保留的是整道题组，其中正确和错误回答都参与相对更新。它也改变了实际训练分布：更偏向当前模型有一定成功机会、但尚未完全掌握的题；极难题可能被长期排除。

3. Token 级平均：不要让长序列的每一步自动变轻

朴素做法先对每条回答取平均，再对回答取平均。DAPO 改为汇总全部有效 token：

J=E[1∑iLi∑i∑t=1Limin⁡{ρi,tAi,clip⁡(ρi,t,1−ϵlow,1+ϵhigh)Ai}].J=\mathbb E\left[\frac{1}{\sum_i L_i}\sum_i\sum_{t=1}^{L_i} \min\{\rho_{i,t}A_i,\operatorname{clip}(\rho_{i,t},1-\epsilon_{low},1+\epsilon_{high})A_i\}\right].J=E[∑i​Li​1​i∑​t=1∑Li​​min{ρi,t​Ai​,clip(ρi,t​,1−ϵlow​,1+ϵhigh​)Ai​}].

LiL_iLi​ 是回答长度，AiA_iAi​ 是组内标准化奖励。长回答因此有更大总权重，但单个 token 不因所在回答更长而自动稀释。这会改变训练目标的加权方式，不应称为纯粹等价的代码优化。它也不等于逐 token 都有独立正确性标签：同一回答仍共享结果优势。

4. 超长奖励：区分不会做与没有写完

作者先实验屏蔽被截断样本的损失，减少把未完成推导判成错误的噪声；进一步加入软长度惩罚。在不超过 16384 token 时不罚，随后 4096 token 缓冲区内逐渐降至 -1，总上限 20480。

这是给定预算下的偏好，不是数学真值。错误原因的区分能降低奖励噪声，但过严长度惩罚也可能不利于真正需要长推导的题。

五、结果：看累计表，也看训练动态

证据 1：表 1，整体配方。 GRPO 为 30，加入超长过滤后 36，再加 Clip-Higher 为 38，软长度惩罚后 41，token 级损失后 42，动态采样后 50。这是逐步累计实验，新增收益依赖已有组件；不能说动态采样在任何 GRPO 上都必定增加八分，也不能据此忽略组件交互。

证据 2：图 2，熵塌缩。 对照展示 Clip-Higher 后策略熵与准确率更有利的训练轨迹。它支持作者设置中探索退化被缓解，不是熵越大越好。图 7 和正文也指出过高熵可能对应乱码、重复与无效探索。

证据 3：图 4、图 5，长度与奖励。 token 级平均和超长处理使训练动态改善。尤其是截断样本过滤，不需要先发明复杂奖励模型，便能降低一种确定存在的标注混淆。但长度曲线健康只是诊断信号，不能代替独立正确率。

证据 4：图 6，动态采样效率。 作者报告额外采样没有显著拖慢该同步系统，并更快达到目标表现。解释涉及长尾回答主导生成等待时间，因此硬件利用与调度很重要；换成不同异步系统或更低有效组比例，结论可能改变。

证据 5：图 1 与 §4.3，步数与泛化。 作者比较 50 分与 R1-Zero-Qwen-32B 的 47 分，并称使用约一半训练步数。每步采样与更新量不同，不能将其写成成本减少一半。§4.3 还指出训练奖励与验证正确率相关性可能很低，直接反对“奖励曲线涨了就说明泛化变好”的理解。

六、贡献与局限

DAPO 的贡献是把长期推理 RL 的几个实现选择明确写成可检查的配方，同时提供代码与数据入口。新意既包括目标函数权重，也包括样本选择与奖励处理，不只是一个算法缩写。

数学数据的易验收性是成功条件之一，迁移到开放式对话需要重新设计反馈。动态采样降低无信号更新，却可能漏掉需要课程或示范才能突破的难题。去除 KL 容许偏离，也需要检查通用能力是否受损；v1 的窄主评估不足以回答所有遗忘问题。

本文的分析是，这些修改共同处理“学习信号在哪里损失了”。优秀实现应把原始采样数、有效题比例、截断率、总 token、更新数与验证成绩一起记录，才能区分优化更有效和只是使用了更多样本。

七、建立理解

自构例子。 两条回答分别长 100 和 1000 token。先对回答平均时，短回答每 token 的系数是 1/2001/2001/200，长回答是 1/20001/20001/2000；改成全 token 平均后，两者都是 1/11001/11001/1100。这是权重重分配，并不是在长回答里新增了更准确的监督。

八、自测与答案

1. 动态采样为什么保留“同题有对有错”，而不是只保留正确回答？

答：组相对优势需要比较。全对或全错时结果奖励没有相对差异；混合成败同时提供提高成功轨迹、抑制失败轨迹的信号。只保留正确答案会破坏这种组内比较。

2. Clip-Higher 是否保证新策略概率不超过旧概率的 1.28 倍？

答：不保证。它裁剪替代目标，使某些方向的奖励不再继续增加；共享参数、多样本更新等仍可能使概率越界。它不是一个对最终概率作硬投影的约束。

3. token 级平均与软长度惩罚是否互相矛盾？

答：不矛盾。前者处理各 token 如何参与梯度，后者表达超出预算的代价；长回答可以得到充分学习权重，同时在越过长度阈值时受罚。但二者交互需要消融，不能只凭直觉确定最优组合。
