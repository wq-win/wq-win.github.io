零基础准备 · 综合

  1. 零基础①：字母、单词与规范书写

    正确区分并书写26个字母的大小写，按字母表排序

    书面英语原创无听力

  2. 零基础②：看懂词的工作，搭出一个完整句子

    区分常见名词、代词、动词与形容词的基本功能

    书面英语原创无听力

三年级 · 上

  1. 三上①：见面、姓名与礼貌表达

    读懂问候、告别、感谢与简单姓名交流

    书面英语原创无听力

  2. 三上②：文具、颜色与课堂指令

    用This is a/an…介绍单个文具，并以It is＋颜色补充信息

    书面英语原创无听力

  3. 三上③：年龄、数字与身体

    读写0—10并用How old are you?询问年龄

    书面英语原创无听力

  4. 三上④：家人、动物与he / she / it

    用he/she/it与is介绍已知的人或动物

    书面英语原创无听力

  5. 三上⑤：身边的植物——认识、需要与爱护

    识别身边常见植物和果实，用This is… / It is…作简短描述

    书面英语原创无听力

  6. 三上累积检查：介绍自己与身边的人物

    在未见过的题目中综合运用姓名年龄、a/an、is与代词、复数、指令

    书面英语原创无听力

三年级 · 下

  1. 三下①：来自哪里、人物关系与物主词

    用Where are you from? / I am from…交流来自哪里

    书面英语原创无听力

  2. 三下②：物品在哪里——方位与指示词

    用in/on/under/near描述物品位置并回答Where is…?

    书面英语原创无听力

  3. 三下③：水果、饮食喜好与礼貌选择

    用I like / I do not like描述一般喜好并用Do you like…?提问

    书面英语原创无听力

  4. 三下④：数量、数字11—100与问句选择

    读写11—20、整十和21—99的常见数字结构

    书面英语原创无听力

  5. 三下⑤：表达自己、请求帮助与有效学习

    用I am＋感受词表达自己，并用I need…说明需要

    书面英语原创无听力

  6. 三下⑥：旧玩具也有新用途——描述、整理与分享

    用old/new、颜色与数量描述玩具，正确表达拥有与位置

    书面英语原创无听力

  7. 三下累积检查：人物、位置、喜好与数量

    在未见过的题目中综合运用物主词、位置、指示词、喜好、数量与基础问句

    书面英语原创无听力

四年级 · 上

  1. 四上①：教室与家——there is / there are

    用there is/are介绍房间里的事物并匹配数量

    书面英语原创无听力

  2. 四上②：人物外貌、have / has与所有关系

    区分be＋形容词与have/has＋名词描述人物

    书面英语原创无听力

  3. 四上③：一餐吃什么——请求、餐具与不可数名词

    用I would like / Would you like…?表达点餐与提供食物

    书面英语原创无听力

  4. 四上④：职业与能做的事——can的完整句型

    读懂常见职业并用What does…do?整体询问职业

    书面英语原创无听力

  5. 四上累积检查：家庭、房间与一顿午餐

    在未见过的题目中综合运用存在句、人物描述、所有关系、食物数量、can

    书面英语原创无听力

四年级 · 下

  1. 四下①：学校、星期与时间表

    读写星期与常见学科，区别on＋星期与at＋具体时刻

    书面英语原创无听力

  2. 四下②：天气、四季与穿着

    用What is the weather like?和It is＋天气词描述天气

    书面英语原创无听力

  3. 四下③：农场、植物与数量表达

    用What are these/those?识别复数动物或农作物

    书面英语原创无听力

  4. 四下④：购物、价格与“谁的”

    用How much…?问价并区分单件is与多件are

    书面英语原创无听力

  5. 四下累积检查：一天的安排与农场商店

    在未见过的题目中综合运用星期时间、天气季节、农场复数、价格与归属

    书面英语原创无听力

五年级 · 上

  1. 五上①：人物、学科与一般现在时第三人称

    用一般现在时描述稳定情况与经常发生的行为

    书面英语原创无听力

  2. 五上②：饮食、数量与because给理由

    用What would you like to eat/drink?写清具体需求

    书面英语原创无听力

  3. 五上③：兴趣、运动与be / do / can分工

    用like＋名词或动词-ing说明兴趣，区分do/play/go的常见搭配

    书面英语原创无听力

  4. 五上④：村庄、自然与空间说明

    用there be的肯定、否定和疑问介绍环境

    书面英语原创无听力

  5. 五上累积检查：社团野餐与社区介绍

    在未见过的题目中综合运用一般现在时第三人称、理由、兴趣搭配、环境与数量

    书面英语原创无听力

五年级 · 下

  1. 五下①：作息、频率与时间顺序

    用一般现在时描述日常作息，按先后组织信息

    书面英语原创无听力

  2. 五下②：月份、日期、季节与节日文化

    读写十二个月份及常用序数词，区分日期与基数数量

    书面英语原创无听力

  3. 五下③：正在发生什么——现在进行时

    书面英语原创无听力

  4. 五下④：规则、礼貌建议与完整短文

    用祈使句与must/must not表达规则，理解should建议强度

    书面英语原创无听力

  5. 五下累积检查：生日活动与图书室规则

    在未见过的题目中综合运用作息频率、日期序数词、现在进行时、规则和连接词

    书面英语原创无听力

六年级 · 上

    读懂城镇地点和文字路线，用turn/go straight/next to给出方向

    书面英语原创无听力

  2. 六上②：周末与旅行计划——be going to和will

    用be going to＋原形写计划并进行否定、一般疑问和wh提问

    书面英语原创无听力

  3. 六上③：职业、工作地点与笔友短文

    用what/where/how及does询问人物职业、工作地点和出行方式

  4. 六上④：感受、身体不适与合适建议

  5. 六上累积检查：城镇旅行计划与人物信息

    书面英语原创无听力

六年级 · 下

  1. 六下①：比较身高、年龄与事物特征

    用形容词比较级＋than作两者比较并匹配比较对象

    书面英语原创无听力

  2. 六下②：过去的状态与规则动词过去式

  4. 六下④：小学—初中衔接——句子、阅读与独立写作

    书面英语原创无听力

    区分there be的存在意义与have的所属意义。

    there be地点介词时间介词社区路线

  5. 一般现在时 用英语写日常生活

  7. 形容词副词和比较 描述人及事物

    区分形容词与副词在句中的作用。
