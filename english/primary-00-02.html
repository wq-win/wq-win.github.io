学习目标

  • P02.1 区分常见名词、代词、动词与形容词的基本功能
  • P02.2 在I am / You are / It is中选对be动词并构成完整句
  • P02.3 把否定、问号与缩写认作句意的一部分

先备与学习方法

前课：en-primary-00-01。先看例子，再遮住答案写出自己的句子。手写时保留空格；不会的词可先查本课词库，复测时不查。

词汇与用法

词/短语 意义 用法提醒
I 我 作主语，永远大写
you 你；你们 英语不因单复数改变这个词
it 它 代替一个事物或动物等
am 是 与I搭配
are 是 本课与you搭配
is 是 本课与it搭配
a 一个 放在单数可数名词前
an 一个 用于元音音素开头的词前
book 书 可数名词
red 红色的 可描述物品
big 大的 常见形容词
not 不 放在be后构成否定

核心讲解

词类是“工作分工”，不是单词长度。book指事物，是名词；I/you/it可以代替人或物，是代词；am/are/is是动词be的不同形式；red/big用来描述，是形容词。同一个词在别的句子里可能承担不同工作，先掌握本课用途。

英语陈述句常按“主语＋动词＋其余内容”排列：I am Anna. / It is red. “我安娜”不能写成I Anna，中间需要am。先记I am、you are、it is，不要把am当成所有“是”的通用翻译。

It is a book.中的book是一个可数物品，用a；It is red.中的red是形容词，不能在它前面随意加a。a/an的选择看后面词开头的音，不只看字母；本阶段先记a book、an apple。否定在be后加not：It is not red. 缩写I'm＝I am，it's＝it is；撇号不是装饰，暂时可以一律写完整形式。

把be移到主语前可提问：It is red. → Is it red? 回答Yes, it is. / No, it isn't. 常见错误：It red漏is；I is搭配错误；It is a red把形容词误当完整名词短语。

例题解析

例1：“它是一本书。”先选主语It，再选is，再加a book，得It is a book. 不能漏a，因为这里指一本书。

例2：把You are Anna.改否定。主语不动，在are后加not：You are not Anna. 不是You not are Anna.

原创阅读

I am Bo. You are Anna. It is a book. It is red. It is not big.

阅读时画出每句的主语和be动词。最后一句的not让意思变成“它不大”，不可跳过。

练习

计分说明：普通学习课最后一题为书面表达，按后附4分量表单独记录；此前每个编号1分，多空/多问在该题内均分。客观题正确率分母为末题前的编号总数。累积检查另按其20分说明计分。

  1. 按本课功能分类：book, I, red, is（名词/代词/形容词/动词）。

  2. 填空：I __ Bo.

  3. 填空：You __ Anna.

  4. 填空：It __ red.

  5. 选a或an：__ book；__ apple。

  6. 改错：It a book.

  7. 改否定：It is big.

  8. 按提示重排：red / is / It（陈述句）。

  9. 把It is red.改为一般疑问句。

  10. 阅读中的书是红色的吗？用完整简短回答。

  11. 阅读中的书大吗？用英文否定回答。

  12. 用I am介绍自己，再用It is描述一本书；写两句。

参考答案与解析 · 完成练习后展开

参考答案与解析

  1. book名词；I代词；red形容词；is动词。根据句中用途分类。

  2. am。I与am搭配。

  3. are。you与are搭配。

  4. is。it与is搭配。

  5. a book；an apple。这里book以辅音音素开头，apple以元音音素开头。

  6. It is a book. 补出be动词。

  7. It is not big. / It isn’t big. not跟在is后。

  8. It is red. 句首大写，句末句号。

  9. Is it red? be移到主语前，句末问号。

  10. Yes, it is. 原文It is red.提供依据。

  11. No, it isn’t. / No, it is not. 依据最后一句。

  12. 例：I am Lin. It is a book. 姓名可变，第二句也可写It is red.；须有主语、be动词与合适结尾。

写作示范与自评

任务（与第12题一致）：用I am介绍自己，再用It is描述一本书；写两句。

参考与说明：例：I am Lin. It is a book. 姓名可变，第二句也可写It is red.；须有主语、be动词与合适结尾。

书面表达4分量表：任务完成1分（须满足题目全部信息及句数要求）；句子结构1分（主语、动词及语序）；词形用词1分（目标词汇、单复数等）；规范书写1分（大小写、空格、标点）。各项部分达成可给0.5分。开放信息允许合理变化，不要求逐字照抄。

复习与达标

隔一天遮住原文重做错题，再换人物或物品写两句新句子。客观题达到80%后进入下一课；追求95%须用未见过的同知识点题复测，并由教师或家长按本课要求检查书面表达。这是本站练习目标，不是学校考试成绩保证。
