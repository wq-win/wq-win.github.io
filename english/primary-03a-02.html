学习目标

  • P04.1 用This is a/an…介绍单个文具，并以It is＋颜色补充信息
  • P04.2 区分a/an的常见实例，理解形容词在名词前的顺序

先备与学习方法

核心讲解

介绍手边一件物品：This is a pen. 颜色可以单独写：It is blue.，也可以放在名词前：This is a blue pen. 不能写a pen blue。this表示这个，it接着指前面说过的物品。

本课记住a pen、a pencil、a ruler、a crayon、an eraser。a/an看的是紧接着那个词的开头音：an eraser，但a white eraser，因为紧接着的是white。不要机械地见到eraser就永远选an。

课堂指令通常以动词原形开头：Open your book. / Write your name. 用Please可以更礼貌：Please sit down.。否定命令以Don't开头：Don't draw on the desk.（不要在桌子上画。）祈使句通常省略you，不必每句都加You are。

拼写观察：pen、pencil开头相同但不是同一个词；black、blue都有bl；white中的wh整体记忆，不用汉字注音。

例题解析

例1：把“这是一把红色的尺子”写成英文。先用This is a ruler.，把red放在ruler前：This is a red ruler.

例2：把Open your book.改为否定指令：Don't open your book.。Don't后面仍用open，不能用opens。

原创阅读

This is my bag. It is green. This is a pencil. It is yellow. This is an eraser. It is white. Please open your book.

阅读时按“物品—颜色”配对，不要认为离某个颜色最近的所有物品都是该颜色。

练习

计分说明：普通学习课最后一题为书面表达，按后附4分量表单独记录；此前每个编号1分，多空/多问在该题内均分。客观题正确率分母为末题前的编号总数。累积检查另按其20分说明计分。

  1. 填a/an：__ eraser；__ pencil。

  2. 填a/an：__ white eraser。

  3. 重排：a / is / This / ruler。

  4. 写出“一支蓝色的笔”。

  5. 把This is a pen.中的pen换成eraser，必要时改冠词。

  6. 把Open your book.改为否定指令。

  7. 写出“请坐下。”

  8. 改错：This is a bag green.

  9. 阅读中包是什么颜色？

  10. 阅读中什么是黄色的？

  11. 阅读最后一句要求做什么？用中文说明。

  12. 选择两件自己的文具，每件写两句：介绍物品、说明颜色。

参考答案与解析 · 完成练习后展开

参考答案与解析

  1. an eraser；a pencil。eraser以元音音素开头。

  2. a。紧接着的white以辅音音素开头。

  3. This is a ruler. 注意a不能漏。

  4. a blue pen。颜色形容词放名词前。

  5. This is an eraser. 要同时改a为an。

  6. Don’t open your book. Don’t＋动词原形。

  7. Please sit down. / Sit down, please. 均可。

  8. This is a green bag. / This bag is green. 结构不同但均正确。

  9. Green. / It is green.

  10. The pencil. / The pencil is yellow.

  11. 请打开书。open是打开，不是合上。

  12. 例：This is a pen. It is black. This is a ruler. It is blue. 实际颜色可不同，须保证句内结构正确。

写作示范与自评

任务（与第12题一致）：选择两件自己的文具，每件写两句：介绍物品、说明颜色。

参考与说明：例：This is a pen. It is black. This is a ruler. It is blue. 实际颜色可不同，须保证句内结构正确。

书面表达4分量表：任务完成1分（须满足题目全部信息及句数要求）；句子结构1分（主语、动词及语序）；词形用词1分（目标词汇、单复数等）；规范书写1分（大小写、空格、标点）。各项部分达成可给0.5分。开放信息允许合理变化，不要求逐字照抄。

复习与达标

隔一天遮住原文重做错题，再换人物或物品写两句新句子。客观题达到80%后进入下一课；追求95%须用未见过的同知识点题复测，并由教师或家长按本课要求检查书面表达。这是本站练习目标，不是学校考试成绩保证。
