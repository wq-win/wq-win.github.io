# 小学英语：从零基础到初中衔接（书面学习版）

## 这套材料是什么

这是给中文初学者编写的原创书面课程：可选零基础准备，之后按三至六年级上下学期组织。共 **45篇完整课文与检查**：2篇可选准备、35篇年级学习单元、8份累积检查（其中六下兼作小学阶段检查）。每篇都有目标、词汇用法、讲解、至少两个例题、原创阅读、分层书面任务、逐题答案与理由。总计553个编号任务和553个对应答案；一个编号中的多个空不冒充多道题。

**不用听力，不提供音频，不要求跟读或朗读录音。**拼写规律只进行文字识别、归类和书写练习；无法据此验证发音或听辨能力。若学校试卷有听力、口语，这部分不在本课程覆盖范围。

**地域与版本边界：**本课程暂以江西地区、人教版体系为参照，学校实际使用的教材封面、ISBN或册次目录尚未核对。不能据此断言江西所有学校使用同一版本。本课程将常见小学书面知识按难度递进，并为已核实的新版主题提供路线；不是官方教材复刻，也不是逐页同步讲义。

[人教社2024年PEP教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995564.html)说明三年级起点、八册的整体安排。新旧官网资源入口存在版本混用：旧入口的同一年级内容不一定代表最新修订本。2022年课程标准只能作为历史参考；已知2025年有修订，但本课程没有完成最新完整标准及全部新版教材的逐条审计，不声称已经完整校核最新版本。

## 两种使用路线

1. **系统补基础：**按目录顺序学习。能规范读写简单单词、认识I am/It is者可跳过两篇零基础准备。新知识首次出现有中文解释；不要因为后期阅读见过一个词，就默认前期学生已经掌握它。
2. **随学校进度：**先查学校实际教材目录，再看下方/版本路线文件的主题对应。本站会重组主题、把部分内容前置或后置；跨册链接是明确的跨册学习，不冒充本学期官方单元。遇到跨册课，先补其先备结构，不能直接把六年级完整语法要求搬给三年级。

**每课建议分2—4次：**第一次看词库与讲解；第二次独立完成练习；第三次按解析订正并解释为什么；隔一天换人物、数量或语境复测。三年级重点从短句到3—4句；四年级形成有关系的小段；五年级练理由、顺序与规则；六年级逐步写50—90词短文。篇幅是本站练习支架，不是假称官方统一字数。

## 80%与95%怎样使用

- 普通学习课：末题书面表达单列4分；前面每个编号1分，多空在题内均分。客观题分数除以其编号总数才是正确率。客观题达到80%后继续，95%作为较熟练的复测目标；写作须另外记录，不能拿客观题分数冒充全能力。
- 20分检查：16分为基本练习目标，19分为高熟练目标。写作4分按任务、结构、词形用词、书写分别评阅。
- 40分小学阶段检查：32分与38分对应80%和95%；写作8分有独立量表。
- 至少在**未见过的同知识点材料**上复测一次，并隔天再检查保持情况。可由教师/家长选择同难度新材料，或者改变原题人物、数字、时间和否定条件；仅背本站原答案不能证明迁移。
- 开放写作需要能判断英语句子的教师或成人评阅；未评阅标“待评”。范文只是一个可接受答案，不是唯一答案。不因合理同义表达、英美拼写变体或真实个人信息不同扣分。
- 这些是本站书面练习目标，**不是80%/95%校考成绩保证**，也不是“读完即掌握”。实际成绩取决于所用教材、试卷权重、词汇保持、陌生阅读、独立写作及未覆盖的听说。
