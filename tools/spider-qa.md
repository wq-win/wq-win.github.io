# 蜘蛛纸牌布局回归

运行：

```sh
node tools/spider-ui-test.js
```

测试使用生产 HTML、蜘蛛纸牌控制器及公共全屏控制器，在无依赖的 Node VM 和最小 DOM 中执行。测试入口只注入内存中的脚本副本，生产页面不提供调试接口。

2026-10-17：15 项测试通过；另有 32 组视口/普通或放大视图的源码尺寸推导。通过项目：

- 初始牌数 104、十列、五轮余牌及十张正面牌；一色、两色、四色的完整牌组组成
- 测试牌阵中全部 104 张已露出点数的按钮，均选择正确位置和连续段；包含 A、10、J、Q、K
- 实际控制器的发五轮牌、撤销、同花连续段移动、翻牌、非法移动、空列禁止发牌、空列接牌、收齐 K 至 A、提示和重开
- 全屏与页面铺满的进入、退出、浏览器拒绝全屏、Esc、旋转事件均不改牌局、选择、撤销历史或横向滚动位置
- HTML 中全屏、重开、撤销、提示、难度、发牌和收齐区均在横向滚动牌区之外
- CSS 十列最小 72px 牌宽、普通文档流堆叠、不再依赖固定的 JS 高度或 top 偏移
- 320px 至 3840px 视口下，点数含 10 使用相同字高且保持在外露牌条内；装饰花色与点数分离，不相互挤压
- A 和 J/Q/K 居中；J/Q/K 保持原 SVG 比例；牌区单独的层叠上下文让选中牌不能盖住置顶退出按钮

这些结果不代表真实浏览器布局、字形像素、触摸命中或原生 Fullscreen API 已通过。真实浏览器复核应另记结果。

## 真实浏览器复核清单

1. 普通视图和全屏分别检查桌面 1440×900、1920×1080、3840×2160；手机竖屏 320×568、390×844；横屏 568×320、844×390。页面本身不得横向溢出；窄屏仅十列牌区横向滚动。
2. 滚动到第十列，确认最后一列完整可见。发牌、撤销、提示、难度及退出按钮仍位于牌区外，不随牌区横向滑走。
3. 比较同宽牌的 A、6、8、9、10、J、Q、K：字号和顶部基线相同；10 不缩小；角标完整；9/10 中部花色不碰角标或彼此重叠；A 与人像居中。
4. 发几轮牌并形成连续段。逐个点击被叠牌遮住主体、仅露出顶端点数的牌；每个点数仍能选择对应连续段。选中段上移后也不能盖住前一张牌的点数。
5. 完成一次移动、翻牌、收齐，再撤销；切换三种难度并重开。检查牌和列的位置更新，不残留旧尺寸空白或重叠。
6. 普通和全屏中来回旋转，保留当前牌、选择、收齐计数和余牌。牌列随宽度调整，长列能继续向下滚动；空列仍能接牌。
7. 在很长的牌列中向下滚动，退出按钮必须持续可见且能点击，卡牌不得覆盖其上。重复全屏进出，并检查浏览器拒绝原生全屏时的铺满回退和 Esc。
8. 在真机上检查横向手势、纵向滚动、页面缩放、刘海/安全区；触控和原生全屏兼容性须以实际浏览器结果为准。
