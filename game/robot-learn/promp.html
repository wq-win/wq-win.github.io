ProMP：一组轨迹怎样经过指定位置？

把轨迹的基函数权重看成高斯分布，而不是只保存一条动作。指定途经点后，用高斯条件化同时调整均值和不确定性。试着把观测噪声调大：约束会变软，绿色均值不再紧贴黄点。

看懂这次更新

1. 用六个归一化高斯基函数表示位置：y(t) = φ(t)ᵀw，w 服从高斯分布。

2. 对带噪声的途经点 y* 条件化：K = Σφ / (φᵀΣφ + σ²)，μ' = μ + K(y* − φᵀμ)，Σ' = Σ − KφᵀΣ。

3. 绿色带表示每一时刻的边缘分布均值 ±2 倍标准差，不是整条轨迹同时落在带内的 95% 保证。蓝线使用同一随机种子，便于比较参数变化。

教学边界

这里用预设的权重均值和协方差演示一维位置轨迹，没有从真实机器人示范训练，也没有实现论文中的随机反馈控制器、速度约束和多关节控制。DMP 通常用吸引子动力学描述运动；本页强调 ProMP 对轨迹分布及条件化的表达，不把两者简化为谁“更好”。
