参数预算与观察

这段动画演示了什么？

ΔW = (α / r)BA，其中 B 的形状为 d × r，A 为 r × k，所以 rank(ΔW) ≤ r。动画按外积逐项累加，展示的是矩阵分解，不是训练的时间步骤。W₀ 本身不要求低秩。

论文采用随机初始化 A、零初始化 B，使初始 ΔW = 0。本页用固定示例数值替代随机数，便于比较。这里没有数据集、损失函数、反向传播或真实语言模型，也不能据此判断不同 r 的任务效果。参数统计仅针对单个无偏置权重矩阵，未包含整个模型和优化器。

试一试：固定 r，把 α 改为 0；再勾选 B = 0，比较两种情况下的结果。随后把 r 从 1 调到 4，观察可训练参数量的变化。
