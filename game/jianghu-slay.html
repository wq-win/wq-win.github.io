本机玩 AI，偶尔开房对战

GitHub Pages 只能放说明页，游戏本体需要在本机跑 Python 服务。 平时各自电脑打 AI；想双人时由房主开服，对方打开房主地址并输入房间号。

一、平时：本机人机对战

拿到 JianghuSlay 项目后，在项目根目录执行：

./scripts/start.sh
# 或明确写：./scripts/start.sh ai
  1. 首次会自动创建虚拟环境并安装依赖
  2. 浏览器打开 http://127.0.0.1:8000
  3. 选「人机对战」→ 选英雄开局

不需要联网，也不依赖别人的电脑。

二、偶尔：本机当服务器开房

房主在项目根目录执行：

./scripts/start.sh host

终端会打印本机与局域网地址。然后：

  1. 房主打开页面，点「创建房间」，把房间码发给对方
  2. 对方用房主给的地址打开（同一 Wi‑Fi 用局域网 IP；不同网络用 ngrok 等隧道链接）
  3. 对方不要再启动自己的服务，直接「加入房间」→ 双方选英雄 → 准备开战

跨网时（可选）

房主另开一个终端：

ngrok http 8000

把 ngrok 给出的 https://… 发给对方。房主电脑关机或隧道断开后，对战不可用。

三、手动启动（备用）

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. uvicorn server.main:app --host 127.0.0.1 --port 8000   # 本机 AI
# 开房改为 --host 0.0.0.0

注意

  • 双人必须连同一台服务器；两端打开的网址要一致
  • 服务重启后房间码失效，需重新创建房间
  • 项目路径示例：本机 Downloads/Project/JianghuSlay（向作者索取最新代码）
