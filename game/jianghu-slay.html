人机对战与房间号双人对战都已部署到公网。点下面按钮即可进入游戏页面。

直接开始玩 源码

免费实例约 15 分钟无人访问会休眠；冷启动可能要等 30–60 秒。服务重启后房间码会失效。

房间号对战

  1. 双方都打开同一个地址：https://jianghu-slay.onrender.com
  2. 一人「创建房间」，把房间码发给对方
  3. 另一人「加入房间」→ 双方选英雄 → 准备开战

本机备选（可选）

不想等冷启动、或要离线玩时，可在本机跑：

git clone https://github.com/wq-win/JianghuSlay.git
cd JianghuSlay
./scripts/start.sh          # 本机人机
./scripts/start.sh host     # 本机开房

源码仓库：github.com/wq-win/JianghuSlay
